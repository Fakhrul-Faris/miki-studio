# Humor Patterns (Miki Studio)

Write from **stolen structure + character voice**, not vibes. Patterns below come from `comedy-autopsy/autopsies/` (deep batch). Cite source `vid_NNN` when you reuse a machine.

## How to use this skill

1. Pick **one** pattern (or combine at most two).
2. Lock **character** (want / flaw / status) before dialogue.
3. Write **punchline / button first**, then shortest path to it.
4. One job per short: one premise, one turn, one button.
5. Prefer **9:16**, 20–60s; call visual beats explicitly for Grease Pencil.
6. After drafting, score against: hook in ~2s, clear turn, button that lands without explanation.

North star tone: **odd1sout staging clarity + Smiling Friends tone control + one hard conceptual turn**.

Full pattern cards + autopsy pointers: [reference.md](reference.md)  
Living index in repo: `comedy-autopsy/patterns_index.md`

## Core joke machines (steal these)

### 1. Tool / institution hell
**Machine:** Simple need → personified system creates friction → user almost wins → system punishes, loops, or only an “illegal” path works.  
**Sources:** `vid_001`, `vid_004`, `vid_008`, `vid_009`  
**Swap:** Any SaaS, maps, docs, tutorial platform, paired apps.  
**GP tip:** Logo-head character + one desk/couch set; escalate locations only if needed.

### 2. Status inversion
**Machine:** Confident attacker / authority → target unfazed or flips power → original high-status character is the casualty or subordinate.  
**Sources:** `vid_017`, `vid_002`, `vid_034`, `vid_013`  
**Swap:** Magic duel, interview, trainer battle, parent lecture.  
**GP tip:** Hold blank/deadpan face on the “winner”; animate the loser hard.

### 3. Literalization
**Machine:** Routine phrase or instruction → audience expects normal compliance → character obeys the words physically/absurdly.  
**Sources:** `vid_045`, `vid_047` (“I just did”)  
**Swap:** Payment verbs, HR speak, safety instructions.  
**GP tip:** Long silent fail beats; oversized wrong prop.

### 4. Visual mid-beat / visual button
**Machine:** Setup in dialogue → **see** the turn (fill bubbles, pocket flyer, spoon) → short button line or none.  
**Sources:** `vid_018`, `vid_019`, `vid_045`  
**Rule:** If the laugh needs a prop gag, don’t explain it in VO.

### 5. Rule of three escalation
**Machine:** Same refusal/request pattern ×3, each gatekeeper bigger; authority snaps; misread snap as another beat.  
**Sources:** `vid_021`  
**Swap:** Confession, support ticket, airport security, parent permission.

### 6. False diagnosis / witch hunt
**Machine:** Slight change → group pathologizes → every defense = more proof → ritual “cure.”  
**Sources:** `vid_046`  
**GP tip:** Tied character stays sane; believers get louder.

### 7. Social avoidance / show don’t tell
**Machine:** Mistake or conflict → character chooses silence → others invent theories → walk-off refuses to explain.  
**Sources:** `vid_023`  
**GP tip:** Two locations; minimal mouth on avoider.

### 8. Expectation gap (relationship)
**Machine:** Humble brag or soft ask → partner overshoots → pride collapses → polite retreat (“let’s watch the movie”).  
**Sources:** `vid_053`  
**GP tip:** One couch; subtitle price pops.

### 9. Object / body committee POV
**Machine:** Organs, appliances, or tools as coworkers with opposing needs → junior part bypasses boss or emotional reveal undercuts.  
**Sources:** `vid_005`, `vid_052`  
**GP tip:** Faces on appliances/organs only; sad specific inventory props.

### 10. Paranoia vs micro-reality
**Machine:** Hero prepares for grand scam → pitch is mostly honest → punchline is a tiny fee / tiny crime.  
**Sources:** `vid_050`  
**GP tip:** One folding table; loop-friendly ending.

### 11. Romance physics fail
**Machine:** Tender promise → logistics/gravity/doorway destroy it → sincere button after mutual suffering.  
**Sources:** `vid_055`  
**GP tip:** Squash-and-stretch; coaching dialogue (“use your weight”).

### 12. Category error + weak legal excuse
**Machine:** Solemn lecture about wrong category → obvious visual proof → weakest possible defense.  
**Sources:** `vid_013`  
**Keep ultra short.**

### 13. Belum walkthrough / kaki tekan
**Machine:** Boss audits N desks → same “not ready” answer → tool excuses → AI-could-do-it moral slam → “make sure siap” (nothing finishes).  
**Sources:** `vid_056`  
**Swap:** Any small studio / agency walkthrough.  
**GP tip:** One hallway; Miki as every department; freeze unfinished UI.

### 14. Share-screen evidence
**Machine:** Casual “share screen” → stall words (“bentar”) → cut to forbidden tabs → unresolved face / preview flicker.  
**Sources:** `vid_089`  
**Swap:** Job hunt, competitor rates, “how to quit,” private DMs.  
**Rule:** Tabs do the laugh — don’t explain.

### 15. Tenure decay / skill inversion
**Machine:** Captioned time ladder → craft peaks mid-tenure → year-one bulk shortcut (zip / bag / dump).  
**Sources:** `vid_095`  
**Swap:** F&B, freelancing, office decks.  
**GP tip:** Same desk; props + face library change; titles carry story.

## Script checklist (before calling it done)

- [ ] Hook readable in first ~2 seconds (line, overlay, or image)
- [ ] One premise sentence you could put in the catalog
- [ ] Clear turn (expectation broken)
- [ ] Button (line, visual, or costume/status change)
- [ ] Visual beats noted separately from dialogue
- [ ] Remakeable without the original IP names
- [ ] Pattern ID(s) cited (`tool-hell`, `literalization`, …)

## Anti-patterns (from this corpus)

- Explaining the joke after the button
- Multiple premises in one short
- Dialogue filling silent visual gag time
- Generic “AI comedy” without a specific prop/word (sad fridge items, ugly fake title, oversized spoon)
- Starting from witty lines instead of the turn
