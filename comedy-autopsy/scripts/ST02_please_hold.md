# ST02 — Please Hold
**Pattern:** P03 Literalization (+ light P04 visual button) · inspired by `vid_045`  
**Format:** 9:16 · ~30s · Grease Pencil  
**Test cast:** Miki + Support Agent (headset, smile that never moves)  
**Status:** draft — kill / keep / rewrite: ___

## Premise
Customer support says “Please hold.” Miki holds — the phone, then the pose, then the entire queue.

## Button (written first)
VISUAL: Agent returns. Miki is frozen mid-hold like a statue. Agent scans a clipboard: “Perfect. Please continue holding.” Walks away.

---

## Script

**LOC:** Tiny apartment. Miki on couch with phone. Support Agent appears in a floating call window.

**ON-SCREEN HOOK:** “Please hold”

**AGENT**  
Thanks for calling. Your wait time is… forever-ish. Please hold.

**MIKI**  
Okay.

**VISUAL:** Miki literally holds the phone with both hands, arms locked, elbows out. Clock ticks. Dust floats.

**MIKI**  
(whisper)  
How long is a hold?

**AGENT** *(on-hold music, muffled)*  
Please hold.

**VISUAL:** Time card: **4 minutes.** Miki’s arms shake. Still holding.

**MIKI**  
Hello?

**AGENT**  
Still holding? Amazing. Please continue to hold.

**VISUAL:** Time card: **22 minutes.** Miki has duct-taped the phone to his palms. Roommate Jay walks through, looks, leaves with coffee. No comment.

**MIKI**  
I think my shoulders quit.

**AGENT**  
We appreciate your patience. Please hold.

**VISUAL:** Time card: **1 hour.** Miki is a rigid statue. Cobweb on elbow. Fly lands on nose. Doesn’t flinch.

**AGENT**  
(returns, bright)  
Hi! Sorry about that. How can I—

**VISUAL:** Agent sees statue-Miki. Tilts head. Checks clipboard. Stamps: **HOLDING — COMPLIANT.**

**AGENT**  
Perfect form. Please continue holding.

**VISUAL:** Call window closes. On-hold music swells. Miki remains. Fly leaves.

**BUTTON — ON-SCREEN:** “Your call is important to us”

**END.**  
(No explaining line.)
