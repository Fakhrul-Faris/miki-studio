# Vid 081 — Autopsy

## Premise
A dad-type customer asks the pharmacy for “Samsudin” like it’s a person; after a search beat, it turns out he means the cough medicine **Sampcodin**—and they don’t have it.

## Hook
Caption: “Bapak-bapak suka ganti nama obat.” Farmaku counter, Tolak Angin stacks, clerk in blue polo. Trope named upfront: fathers rename drugs. Customer: “Mas, ada Samsudin.”

## Setup
Clerk treats it as a human: “Samsudin? Ada apa? Bentar ya? / Tunggu ya.” Goes to look. Returns with the wrong frame—“Ini pak, Samsudinnya?”—still thinking person/presence. Customer: “Obat.” Clarifying ladder: “Obat? / Obat apa, pak? / Obat batuk.” Service detective work from false proper noun.

## Turn
Clerk decodes: “Sampcodin, bapak. Sampcodin.” / “Ganti namanya.” / “Ganti namanya? / Iya, satu dah boleh.” The turn is linguistic forensics—one phoneme shift (Sam-su-din → Samp-co-din) unlocks the SKU. Caption thesis proven.

## Punchline
“Ada gak? / Gak ada. / Gak ada, bapak.” After all that decryption, stock = zero. Effort comedy: solved the riddle, lost the sale. “Ayo dulu lah. / Kalau bapak Sampcodin. / Sampcodin. / Hei!”—still drilling the correct name into the dad as he leaves.

## Reaction / Button
Clerk reaction faces (grit teeth / head-tilt disbelief) under the same caption—workplace PTSD loop. “Hei!” as the last snap when the wrong name threatens to return.

## Why it works (or doesn't)
- **Client terminology hell** — same machine as quiet lasagna, but with false personhood.
- **False lead** — search for a man named Samsudin is the mid-bit; medicine is the reveal.
- **Double punch** — (1) name decode (2) out of stock.
- Clean for Miki: client asks for “Canva Pro Max Ultra” meaning Figma seat.
