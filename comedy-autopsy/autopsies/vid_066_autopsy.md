# Vid 066 — Autopsy

## Premise
Same employee asks the boss for Raya leave—but each cut resets the **salary overlay** (RM1800 → RM3000 → RM5000 → RM10,000), and the ask’s confidence, gifts, and destination scale with the paycheck.

## Hook
Long conference table, boss-POV. Overlay: **POV : MINTAK CUTI RAYA IKUT GAJI** + **GAJI : RM1800**. Worker stands far end, small, earnest. Low salary = timid leave culture in one card.

## Setup
Ladder of the same job, different pay labels (frames): RM3000—“raya ni saya kena balik Kelantanlah bos”; RM5000—casual “eh bos raya mana tahun ni.” Transcript is one continuous Malay/English mash (Kelantan trip, “cuti seminggu,” thank-yous) but the *edit* is salary chapters. Boss keeps saying “Boleh”—permission isn’t the joke; *how* they ask is.

## Turn
At higher tiers, leave becomes lifestyle theater: product box / “kad bos” gift handoff (**GAJI : RM10,000**), Tok food for Mak, flattery, then UK talk—“raya kat UK ke tahun ni.” ASR: “keluang,” “klantat,” “cintis minggu,” “tuah saya pergi sebulan” = noisy travel/leave chatter; trust overlays + Kelantan → UK escalation.

## Punchline
Top-salary beat: employee treats a month abroad / boss UK trip as negotiable fluff—“alah tak pe lah bos” / “Bos nak apa-apa di UK, cakap-cakap.” The punch isn’t denial—it’s **entitlement volume** matching the yellow salary number.

## Reaction / Button
Hold the RM10,000 lean-in smirk after the soft “tak pe.” No boss rage required; the button is status comfort. Loop-friendly: cut back to RM1800 timid stance for contrast edits.

## Why it works (or doesn't)
- **Rule of salary** — one ask template × rising gaji overlay = instant class comedy without new locations.
- **Gift as leave tax** — box/kad/food bribes appear only when pay is high enough to “invest” in the boss.
- **ASR note** — Whisper glued multiple takes; do not invent clean UK dialogue—remake from overlays: Kelantan week → gift → UK month.
- Risk: without clear salary cards, it reads as random suck-up; the yellow `GAJI :` text *is* the joke machine.

## Remake notes
- Steal the machine: **same leave request, salary HUD changes the performance.**
- One office table; swap only overlay + posture (far/timid → close/gift → UK casual).
- Props: one branded box (“gift for boss”) that only appears at mid/high tier.
- English: “POV: asking for PTO by salary band” — $2k whisper / $5k “gotta see family” / $10k “I’ll be in London, ping me.”
- Button: freeze on high-salary shrug; optional hard cut to low-salary version for the laugh.
