# Vid 072 — Autopsy

## Premise
Sleep-deprived retail clerk still shows up — and drives the POS with a **stapler on the mousepad** while the real mouse sits unused. Caption does premise; prop does punch.

## Hook
English overlay locks the POV: **“POV: you slept 3 hours and still came to work.”** Hardware/flooring counter (FloFX, Schluter Systems, Afterpay stickers). Clerk’s thousand-yard stare already sells brain fog before you notice the hands.

## Setup
Left hand correct on keyboard. Right hand grips a black **BOSTITCH** stapler placed exactly where a mouse belongs on a white mousepad. Actual wireless mouse inches away, ignored. Red traffic cone in frame for “worksite” texture. No spoken setup — caption + wrong tool do all the work.

## Turn
He “mouses” with the stapler — micro-drags on the pad as if the cursor should move. Autopilot muscle memory fires on the wrong object. Fatigue made literal as **tool category error**.

## Punchline
Punch is simultaneous with the turn: viewer reads the POV line, then clocks stapler ≠ mouse. The unused real mouse is the silent witness / second punch.

## Reaction / Button
No dialogue button. Hold vacant face + stapler. Optional end micro-beat: brief awareness glance at the stapler without fixing it — awareness without competence.

## Why it works (or doesn't)
- **Literalization of fog** — exhaustion = one wrong office tool.
- **Caption = premise; prop = punch** — zero need for spoken jokes.
- **Business-specific set** — tiling/flooring brands make it feel like a real shop, not a generic desk.
- ASR empty by design (`language=nn`); rejuice confirmed via dense frames — gag is static hold comedy.
- Risk: if stapler and mouse aren’t both readable in 9:16, joke dies — push both into lower third.
