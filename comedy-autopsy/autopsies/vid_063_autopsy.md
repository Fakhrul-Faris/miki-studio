# Vid 063 — Autopsy

## Premise
**POV: INTERN TAKBOLEH PAKAI** — mandatory **Sesi Kaunseling** before firing; every accusation meets the same shield: “Saya kan intern je.”

## Hook
Whiteboard: **Sesi Kaunseling**. Boss: can’t fire without this session, so “Apa masalah kau? Kenapa… staf-staf komplir pasal kau ni?” Counseling is paperwork for an already-decided dump.

## Setup
Intern: “Sorry Boss, saya tak tahu. Saya kan intern je.” Boss tries performance: why only one office day a week? (“daripada seminggu, sehari…”). Same answer: “Mana saya tahu? Saya intern.”

## Turn
Boss escalates to threats: “Kau nak aku fainkan kau ke? Kau jawab lelew sikit.” Intern flips interpersonal: “Kau nak lipik saya balik?” Power struggle becomes slap-threat comedy; still no substance.

## Punchline
Third loop, slightly broken ASR: “Sorry, Boss. Saya tak tahu. Saya internal.” Same get-out-of-jail card, worn smoother.

## Reaction / Button
“Apa kena-mena, Bang?” Boss left without a lever—policy forced the meeting; intern policy (“I’m just an intern”) voids the meeting.

## Why it works (or doesn't)
- **Institution hell** — counseling required → counseling useless.
- **One-line force field** — “saya intern” answers complaints, performance, and threats.
- **Role mismatch** — boss wants a performance review; intern only has a status label.
- ASR wobbles (`fainkan`/`fire`, `lelew`, `lipik`/`slap`, `internal`/`intern`); joke machine is the repeated defense, not polished wording.
