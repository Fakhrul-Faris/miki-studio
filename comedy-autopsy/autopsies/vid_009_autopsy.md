# Vid 009 — Autopsy

## Premise
Filling out a PDF turns into inter-app bureaucracy: Acrobat needs an update, Creative Cloud needs Acrobat closed, Acrobat won’t die — until Task Manager is summoned.

## Hook
Hero asks **Adobe Acrobat** (red-A head behind a desk) to fill a form; Acrobat holds paper, friendly at first (hook frame). “Yeah, sure.”

## Setup
Immediate reversal: “Oh, actually, I can’t do anything anymore because there’s this new update that I need.” Auto-update was supposed to be on — Acrobat shrugs “Yeah?” Hero pivots to **Creative Cloud** (rainbow C icon at desk with glowing **UPDATE** orb, punchline frame).

## Turn
Circular dependency loop in dialogue:
- Creative Cloud: close Acrobat first.
- Acrobat: “Yeah, sure. Have a good night.” — then doesn’t.
- Hero to **Task Manager**: “Yes, boss?” / “This one.”
- Creative Cloud still refuses: “Not until you close out of **all instances** of Acrobat.”
- Hero: “Acrobat is nowhere on the task bar.”

## Punchline
Stalemate beat — Cloud repeats “Close it first, and then we’ll talk” while the form waits. External shame arrives: “Hey, people are wondering if you’ve filled out that form yet.” Hero: **“I’m working on it!”**

## Reaction / Button
Hero snaps: **“Task Manager, nuke it.”** / “You’re the boss.” End frame is a full-screen white flash — total process kill as literal explosion.

## Why it works (or doesn't)
- **Dependency hell as sitcom cast** — each app has a personality and a blocking condition.
- Rule-of-three escalation: ask → update chain → kill command.
- Task Manager as enforcer is a satisfying power flip (user finally has a boss character).
- Visual logo-heads make abstract software fights readable without UI screenshots.

## Remake notes

- Swap Adobe for any paired tools (printer/scanner, IDE/plugin, game/launcher).
