# Shot Analysis — Zalando delivery tram ride (~30s)

Source: `reference-library/zalando/source.mp4`
Extracted via `tools/shot_extractor.py` (scene-cut detection + fixed-interval fallback; required a `-pix_fmt yuvj420p` fix in the extractor for this source's limited-range color). 13 real shots, all inside one continuous location.

**Reference use:** camera, lighting, composition and location DNA only. Do not carry over the Zalando branding/box design or any on-screen text — those are the source ad's, not ours.

**Style summary:** an entire spot shot inside a single vintage subway/tram carriage — red velvet bench seats, warm wood-veneer paneling, chrome stanchions — as a parade of fashionably dressed riders each carry a delivery box. A fashion-editorial "runway" premise: the aisle becomes a catwalk. Strong anchor for any single-set, multi-character "parade/procession" beat, or for a moody warm-interior transit/waiting-room location.

## Cross-shot notes for prompt-writing

- **One location, one continuous set — the entire spot is variation through camera angle and character, not location changes.** A strong anchor for a Meikigo beat that needs to hold a single set (e.g. the barbershop interior) across many different shots/characters without re-establishing it each time.
- **Recurring bookend device: perfectly symmetrical top-down shots** open and later echo mid-spot (Shots 1 and 11) — a graphic, brand-forward framing technique worth borrowing for a hero product or an opening/closing beat.
- **Deliberate lighting variation within the same set** carries the piece's rhythm: warm-neutral (most shots) → deep low-key near-black (Shot 6) → saturated red practical (Shot 7) → soft bokeh dreamlike (Shot 8) → back to warm-neutral. Confirms (again, alongside the Kaufland reference) that lighting shifts inside one location are an effective way to vary mood/pacing without changing sets.
- **The "frame within a frame" door-window shot (Shot 5)** is a distinctive, reusable composition device for a two-character beat in a vehicle/doorway setting.
