# Motion Design Analysis — "Sleeko" (~45.6s, 16:9, 1276x720)

Source: `reference-library/sleeko/source.mp4` (originally `Motion Design/Sleeko (MD).mp4`)
Extractor: 23 shots. Re-derived into 11 beats from a 0.75 fps sheet; times ±1.5s. Frames in `shots/` are named by timestamp.

**Reference use:** headline-on-white with a soft lavender wave, icon pop-ins, floating card collage, footage-with-UI demos, cloud end card. Do not carry over the brand name ("HowDo"), logo, copy, or footage. Describe generically.

**Style summary:** a SaaS/app promo. Palette: white with a lavender/purple gradient wave at the bottom, pastel purple/pink/orange glows, one saturated purple accent. Type: centered medium-weight sans, sentence case, with small icons dropped between words. Three modes: (A) centered sentence on white, (B) 3D icon/card collage on pastel gradient, (C) photo/video with a UI overlay.

## Cross-beat notes
- **White type cards with a gradient wave** separate the busier gradient and footage beats.
- **Words swap in place** (same center position), so text feels like one line changing rather than many slides.
- **Inline icon replacing a word** is a reusable device.
- **Rhythm:** fast text swaps (~1.3s) in the first third, slower use-case demos (~4–8s) in the middle, a slow atmospheric end.
