# Calibration anchors (craft-fundamentals §3)

Frames from our own judged work. The independent critic looks at these **before** scoring a render, so a score means
the same thing every time. A render closer to a `-1` frame than to a `-2.5` frame scores ≤ 4/10.

| File | Level | Verdict (user's words) | Shows |
|---|---|---|---|
| `A-1_clay-boxes_rejected.png` | A · 1 | "world too empty, building too plain, no texture, shape too basic, lighting too cheap" | primitive boxes, flat grey light |
| `A-1_ex35-preview-whitewash_rejected.png` | A · 1 | "white washing … lack of texture … world is pretty empty" | white blocks with no value range or detail |
| `A-2_ex35-final.png` | A · 2 | shipped after the notes | toned whites, relief, signboard, real kiosk, props |
| `A-2.5_ex29-v1-baseline.png` | A · 2.5 | "this is the new baseline for style A" | dense real shopfront, warm subject light, posed figure. (Dark world: an anchor for **density and light**, not for colour.) |
| `B-1_ex34-plain_rejected.png` | B · 1 | "plain back, not enough detail" | big empty flat planes, low contrast |
| `B-2.5_ex33-baseline.png` | B · 2.5 | "i like the ex33 better" (B baseline) | many small readable objects, words on objects, hard light |

Add an anchor the same day the user judges a frame (approved or rejected). Keep the user's words.
