## CREATIVE_INTENT
"When both scenes share a similar visual design — the same UI element, a similar layout, even matching colour
blocks", drop in a cut and it lands. Combining same motion and same design in one cut gives the strongest result.

## STE_PROCEDURE
1. Before designing screen B, copy one block from screen A (position, size, colour).
2. Place it at the same screen position in B.
3. Cut on the word.
4. For the combined version, give that block the same motion on both sides.

## AGENT_EXECUTION
UI spec: name the shared block ("green total bar, y 62 %, h 9 %") in both screens. HyperFrames: reuse the component.

### Worked example
Topic: "Semak duit masuk sebelum serah barang" (generic).
- BEFORE: order chat screen → cut → banking app screen, different layouts.
- AFTER: the chat's green "RM120 diterima?" bar sits at y 62 %; cut on "semak"; the banking screen's green "RM120 masuk" bar is at the same y and slides up 4 % on both sides of the cut.

### Check
- Is one block identical in position/size/colour across the cut?
- Is the cut on a word?
- For a key join, is motion matched too?
