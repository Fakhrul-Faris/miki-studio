## CREATIVE_INTENT
Ideas already exist; "what turns them into art is how you interpret them". Paul Schrader's exercise: "Write down your
biggest personal problem. Not a plot idea, not a character… Then ask yourself, what's the metaphor for that?" Cuarón,
broke after a failed project, said "I feel like I'm falling in the damn void" → Gravity: "He didn't write about being
broke… He wrote what it felt like." District 9 (apartheid as aliens in slums) landed because it was lived; Blomkamp's
later films "started from concept… They felt designed."

## STE_PROCEDURE
1. Write the viewer's felt problem in their words, not the topic's ("rasa macam duit hilang sendiri").
2. Ask "what does that feel like physically?" and write 3 object images.
3. Keep the image an everyday object can literally do (a leaking tin, a melting ice block).
4. Put the image in the spoken line, so showing it is literal.
5. Check the image comes from real lived experience, not a designed concept; else drop it.

## AGENT_EXECUTION
Concept note in `episode.md`: "Felt problem: … → object image: …". Use it for frame 0 or the hook line only; the
mechanism stays literal.
### Worked example
Topic: small daily spending (RM8 kopi, illustrative).
BEFORE (concept): "Mari faham konsep perbelanjaan kecil yang berulang."
AFTER: felt problem "gaji masuk, tapi hilang tak tahu ke mana" → image "dompet bocor". Line: "Dompet korang bocor —
RM8 sehari, RM240 sebulan." Shot: a wallet on a café table, notes slipping out one by one on each number word.
### Check
- Is the felt problem written in the viewer's words?
- Is the image spoken in the line, not only shown?
- Can one everyday object perform it literally?
