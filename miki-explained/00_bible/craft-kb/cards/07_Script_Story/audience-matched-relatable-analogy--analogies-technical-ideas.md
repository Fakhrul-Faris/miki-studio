## CREATIVE_INTENT
Assess the audience's technical level first, then pick a comparison that is universally understood (cloud computing as
a library vs a bookshelf: more space, more access).

## STE_PROCEDURE
1. Before you choose an analogy, check whether the concept can be shown literally; if yes, do not use one.
2. Name the audience level: our default is a 12-year-old, Malaysia, everyday life.
3. Pick a comparison object every viewer has touched (tabung, laci duit, pasar malam, rice cooker).
4. Reject any comparison that needs its own explanation.

## AGENT_EXECUTION
Use in the script line and carry the same object into the shot-list row so the line can be shown literally as the
analogy object (Style D hero object).

### Worked example
Topic: why an e-wallet "balance" earns nothing (illustrative).
BEFORE: "Duit dalam e-wallet tak ada pulangan sebab ia bukan akaun simpanan berfaedah."
AFTER: "Duit dalam e-wallet macam duit dalam tabung ayam. Simpan setahun, RM500 tetap RM500."

### Check
- Was a literal visual impossible before choosing an analogy?
- Would a 12-year-old in Malaysia know the comparison object without explanation?
- Is the analogy object one physical thing we can build as the hero?
