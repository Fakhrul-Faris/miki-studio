## METADATA
07_Script_Story | general | script beat, shot-list rows for that beat

## CREATIVE_INTENT
Keep each beat focused: assign one simple visual metaphor to each core idea rather than stacking several at once.
Stacked metaphors (a bridge, then a key, then gears for the same idea) make the viewer decode images instead of
following the idea.

## STE_PROCEDURE
1. List the script's beats (Hook, Open loop, Mechanism, Proof↔Payoff, End).
2. For each beat, list every metaphor in its lines and its shot-list rows.
3. If a beat has more than one metaphor, keep the one closest to the literal subject and delete the rest.
4. Before adding a metaphor to a beat, check the line itself is a metaphor; otherwise show it literally.
5. Carry the kept metaphor's object through all of the beat's setups (new angles, new states), not new objects.

## AGENT_EXECUTION
Add a "metaphor" note per beat in the script block (`none` or one object). In the shot list, every row of that beat
reuses the same hero object.
### Worked example
Topic: "Kenapa simpan duit kecemasan dalam akaun lain" (everyday money, illustrative).
- BEFORE: Mechanism beat — "Duit kecemasan tu macam payung" (umbrella), then "dia benteng banjir" (flood wall), then a
  safe opening. Three images, one idea.
- AFTER: Mechanism beat keeps one — a real tin coin bank (tabung) on a shelf: "Duit kecemasan duduk dalam tabung lain"
  → next setup the tabung from above with RM 3,000 counting up → next setup the main wallet empties but the tabung stays
  full (accent on the tabung). Metaphor note: `tabung (literal object)`.
### Check
- Does each beat have at most one metaphor?
- Is the metaphor used only where the line itself is figurative?
- Do all setups in the beat reuse the same object?
