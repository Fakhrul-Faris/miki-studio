## CREATIVE_INTENT
"Circle back: return to the cold open or central question with new meaning." "Quotable close: end on a concise takeaway
line that summarizes the shift in understanding."

## STE_PROCEDURE
1. Before you write the end, reread L01.
2. Bring back L01's object or phrase, now seen with what the viewer has learned.
3. Write the shift in understanding as a ≤ 7-word question the viewer can take a side on.
4. End the last shot on frame 0's object and framing.

## AGENT_EXECUTION
L10 = the circle-back (callback to L01's phrase), L11 / end text = the question. Shot list: last row copies row 1's
camera so the loop is seamless.

### Worked example
EX46.
- BEFORE: end "Jadi hati-hati masa sale ya. Follow untuk tips lagi."
- AFTER: L10 "Jadi lain kali nampak 'diskaun 50%'…" (callback to the RM299 → RM149 tag) L11 "50%… dari harga apa?"
  Last shot = the frame-0 tag macro.

### Check
- Does the end reuse L01's object or phrase?
- Is the end text a ≤ 7-word question, with no follow request?
- Does the last frame match frame 0?

## NOTES
- ⚠ Takeaway statement → question, per house rule.
