## CREATIVE_INTENT
"Start with the change, not the script. Write the last frame first: what does the world look like once your product is
in it? Then write the first frame: the same world without it." The middle is only "the moments that move the viewer from
one frame to the other". Narration "says what the drawings can't. Cut every line that describes what's already on
screen." Lendi tells a home loan story in 16 s: "Write your story in 3 frames: the mess, the choice, the result. If it
needs a fourth frame to make sense, cut the third." For plans with levels (AXA, 4 levels): "give each one its own before
and after. If a level has no after frame, fix it or cut it."

## STE_PROCEDURE
1. Write the last frame first: the hero object in its after-state, one sentence.
2. Write frame 0 next: the same object, same framing, in its before-state.
3. Write the story in 3 frames: mess, choice, result.
4. If the story needs a 4th frame to make sense, cut the 3rd and rewrite.
5. Fill the middle with only the beats that move frame 0 to the last frame.
6. For each step/level, write its own before and after; cut any step with no after.
7. Strike every narration line that only describes what is already on screen.

## AGENT_EXECUTION
In `episode.md`, above Script v1, write two lines: `Last frame:` and `Frame 0:` (same object, same camera). These feed
the shot list's first and last rows (RECIPE-D loop). Then write the 3-frame line (`mess → choice → result`) and map it:
mess = L01–L02 (hook + open loop), choice = L03–L08 (mechanism / steps), result = L09–L11 (payoff + end question). For an
S16 how-to, each step row in the shot list must name its own before → after state change.

### Worked example
Topic: a kedai runcit in Kajang whose shelf has expired stock (illustrative).
- BEFORE: writer starts at L01 with "Ramai kedai rugi sebab stok" and discovers the end at L11.
- AFTER: Last frame: the same shelf, front row all newest dates, one tin glowing accent. Frame 0: that shelf, close, a
  dented tin with last month's date. 3 frames: mess (tins mixed, 6 expired) → choice (oldest to the front, every
  Monday) → result (0 expired, RM36 not thrown away — 6 tins × RM6, illustrative). L11 on frame-0 framing: "Stok lama
  kat depan… atau kat belakang?"

### Check
- Are `Last frame` and `Frame 0` written before any line, as the same object and framing?
- Does the story fit mess → choice → result without a 4th frame?
- Does every step have its own after-state?
- Is there no voice line that only repeats what the picture shows?
