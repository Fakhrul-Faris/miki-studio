## CREATIVE_INTENT
"Each bit gets stronger thanks to metaphors and examples. The metaphors show us the shape of each new idea so that the
mind knows how to recognise it." Experience simulator ← flight simulator (pilots practise so they don't make real
mistakes); then "a single strong example": Ben & Jerry's has no liver-and-onion ice cream because you can simulate the
flavour and say "yuck" from your armchair. "Then you totally get what it is." Synthetic happiness ← the immune system.

## STE_PROCEDURE
1. For each block, write its shape as a familiar thing the viewer already uses ("macam …").
2. Check the familiar thing shares the block's working parts; drop it if not.
3. Write one strong example of the block happening, with a concrete object or number.
4. Use one example only; delete runner-up examples.
5. If the line budget allows only one, keep the example.
6. Let the example be a little surprising or funny so it sticks.

## AGENT_EXECUTION
Per block in the outline: "shape: …" and "example: …". The example becomes the shot-list setup (shown literally); a
spoken metaphor may get its own setup only if it is the line's words. Never stack two metaphors on one block (see
`one-metaphor-per-beat--visual-analogies.md`).
### Worked example
Block: "kos tetap" for a dobi layan diri (illustrative numbers).
BEFORE: "Kos tetap ialah kos yang tidak berubah dengan jumlah jualan, contohnya sewa, insurans, lesen dan gaji."
AFTER
- Shape: "Kos tetap ni macam sewa bilik — guna ke tak, tetap bayar."
- Example: "Sewa kedai RM2,500. Sebulan tak ada orang basuh pun, tetap RM2,500."
Shot: the rent invoice on the folding table, the empty washers behind it out of focus; "RM2,500" stays while a usage
counter beside it reads 0.
### Check
- Does each block have at most one metaphor?
- Does each block have exactly one concrete example?
- Is the example shown literally in the shot list?
- Is the metaphor only shown when it is spoken?
