## CREATIVE_INTENT
"The best place to start when you're writing a story is the end." Work out where you want to take the viewer and work
backwards. He calls the last line "the last dab": so memorable that if it were all someone heard, they'd share it. Short
videos loop, so the last line sets up the first lines on replay — like baseball's nine hitter setting the table for the
top of the order. Christopher Nolan (Tenet, Inception, Interstellar) had to work out the end before building the
conflict. Tactic: write the first and last lines, leave space between, then fill in the middle "dance".

## STE_PROCEDURE
1. Before writing any middle line, write L01 and the last line.
2. Make the last line ≤ 7 words on screen, a question the viewer can take a side on.
3. Test it alone: would someone who heard only this line want to answer or share it?
4. Check that the last line leads back into L01 on replay (same object, same tension).
5. Leave the middle empty; then fill it with but/therefore beats from L01 to the end.

## AGENT_EXECUTION
Script v1 skeleton: L01, a gap of ~9 empty rows, L11. Shot list: the last row's framing matches row 1 (RECIPE-D loop).

### Worked example
Topic: fake "harga asal" on sale tags.
BEFORE: last line written last: "Jadi, hati-hati masa sale. Follow untuk tips lagi." (statement + follow request.)
AFTER (written first): L01 "Diskaun 50%. Tapi harga asal tu, pernah wujud ke?" Last line: "RM99 ni, murah betul ke
korang kena?" Frame: back on the same RM199→RM99 tag as frame 0; on replay, L01 answers "pernah wujud ke?" again.

### Check
- Were L01 and the last line written before the middle?
- Is the last line a ≤ 7-word question the viewer can take a side on, with no follow request?
- Does it loop into L01 and frame 0?
