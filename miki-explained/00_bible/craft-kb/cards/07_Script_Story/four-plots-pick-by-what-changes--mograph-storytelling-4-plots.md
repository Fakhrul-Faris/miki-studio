## CREATIVE_INTENT
"Most motion graphics videos that promise storytelling are moving slides. An icon slides in. A counter ticks up. A logo
spins… Nothing happens to anyone. So nothing sticks." A story needs "a change you can watch". The working stories run one
of four plots: **Stick Figure** (one person whose day changes), **Tidy-Up** (draw the mess, then clear it in one
continuous move), **Courier Run** (follow one thing — a molecule, a record, an ingredient — start to finish),
**Playground** (set an abstract idea in a world the viewer already knows: a stadium, a carousel, a road trip). One
question picks it: what does the viewer need to see change — a person, a mess, a hidden process or an abstract idea?
"One plot per video. If two feel right, make two short videos."

## STE_PROCEDURE
1. Before you write line 1, write one sentence: "The viewer must see ___ change."
2. Pick the plot from the blank: a person's day → Stick Figure; a messy workflow → Tidy-Up; a process nobody sees →
   Courier Run; an abstract idea → Playground.
3. Pick exactly one plot. If two fit, split into two episodes.
4. List every planned scene/setup; next to each, write what changes in it.
5. Give any scene whose answer is "nothing" a change from the plot, or cut it.
6. Check the plot's own rule (below) before drafting lines.

Plot rules by source (VALUES BY SOURCE):
| plot | the move | test |
|---|---|---|
| Stick Figure | buyer's feeling at start and end, product in the middle (Natera) | last scene shows a person (adapted: the person's object), not a feature |
| Stick Figure | someone else who worries or pays gets a scene (PharMerica) | the second payer appears |
| Stick Figure | show the product in 3 places the buyer actually is when the task arrives (AgilLink) | not every scene is an office |
| Stick Figure | hard mechanism → tell it through one group of people it pays (Earth Token) | viewer can say who benefits |
| Stick Figure | build a 15 s spot round one real customer sentence about speed: "under 10 minutes" (Ownr) | you can quote someone |
| Tidy-Up | one object stands for the old way; remove it on screen (Wirepas) | the mess has a single picture |
| Courier Run | one everyday object traced end to end (Maersk pizza) | viewer can name the object afterwards |
| Playground | a world whose rules the buyer knows, kept to the end, that can change (EU carousel) | the metaphor can be stopped |

## AGENT_EXECUTION
Write the plot name and the "must see ___ change" sentence at the top of Script v1 in `episode.md`. Then in the shot
list, the `State change and events` column must be non-empty on every row; a row with no change is cut or given one.
For S16 how-tos the plot is usually Tidy-Up (the problem state cleared step by step) or Courier Run (one RM note / one
order / one receipt followed through the steps). Stick Figure → the person's object carries the change (till drawer from
jammed to tidy; phone screen from 12 tabs to one app).

### Worked example
Topic: a nasi lemak stall in Shah Alam that loses track of daily takings (illustrative numbers).
- BEFORE (moving slides): L04 icon of a notebook slides in; L05 a counter "RM480" ticks; L06 a logo spins.
- AFTER (Courier Run, one RM10 note): "Must see: where one RM10 note goes." L01 the RM10 lands in the tin. L04 it splits
  into RM4.50 rice-and-sambal cost, RM1.50 packaging, RM4 left. L06 the RM4 is the only part that's yours. L11 back on the
  tin: "Dari RM10 tu, berapa korang betul-betul simpan?"

### Check
- Is there one written sentence "the viewer must see ___ change"?
- Is exactly one plot used?
- Does every shot-list row name a change (no "nothing" rows)?
- Stick Figure adapted: does the change happen on the person's object, with no people on screen?

## NOTES
- Visual gaps: the 30 example videos are described in prose only; their frames are not recoverable here.
- Length data from the source: most of the 30 run 1–2 min (17 of 30); shortest Ownr 0:15 and Lendi 0:16, each with one
  change; longest Labuan IBFC 2:52. "Fit the length to the change, not the feature list."
- 2D vs 3D (source FAQ): 2D for people, workflows, ideas; 3D when the story happens inside something physical (Nalco's
  heat exchangers, ARNITEL's membrane); Moderna mixes both. Our Style D is 3D-object by default; UI scenes are 2D.
- ⚠ Stick Figure character animation ("people working on the move") conflicts with no-people / figures-pose-only →
