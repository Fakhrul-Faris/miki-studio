## CREATIVE_INTENT
Gilbert "didn't try to explain his complicated idea in one big leap. He got there piece by piece": prefrontal cortex →
experience simulator → impact bias → synthetic happiness. "Like a tower, each new block of information supports the
next new block." Each block gets a name and is made stronger with a metaphor or example before the next is laid.

## STE_PROCEDURE
1. Write the payoff idea in 1 sentence.
2. List the 2–3 ideas the viewer must hold before the payoff makes sense, in dependency order.
3. Give each block a short plain name (≤ 3 words) the voice can repeat.
4. Introduce one block per line or line pair; never two new names in one line.
5. Before laying block N+1, check block N was shown with an object or number.
6. In the payoff line, name the earlier blocks it rests on (re-use their names).

## AGENT_EXECUTION
Outline in `episode.md`: "Blocks: A → B → C → payoff". Each block owns one or two shot-list setups and keeps a visual
token (the hero in a specific state) that reappears in the payoff setup, so the payoff frame literally stacks the
earlier states. With ~11 lines, budget 2–3 blocks max.
### Worked example
Topic: "Kenapa kedai bundle boleh jual baju RM10 dan masih untung?" (illustrative numbers).
BEFORE: "Kedai bundle untung sebab beli borong, kos rendah dan jualan laju." (three ideas in one line)
AFTER
- Block A "harga bal": "Satu bal baju terpakai, 100 helai, RM300. Tiga ringgit sehelai."
- Block B "baju bintang": "Dalam bal tu, ada 5 helai jenama. Jual RM80 sehelai."
- Block C "baki RM10": "95 helai lagi, jual RM10. Dapat RM950."
- Payoff: "Harga bal RM300. Baju bintang RM400, baki RM950. Satu bal, RM1,350."
### Check
- Is the payoff written first, with 2–3 named blocks before it?
- Does any line introduce more than one new name?
- Is each block shown with an object or number before the next?
- Does the payoff line reuse the block names/states?
