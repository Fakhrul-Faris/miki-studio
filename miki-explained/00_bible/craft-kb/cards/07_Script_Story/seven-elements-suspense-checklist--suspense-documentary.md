## CREATIVE_INTENT
Seven elements: **strong characters** the audience cares about; **conflict or dilemma**; **pacing** that controls when
tension rises and releases; **high stakes**; **uncertainty and unpredictability** (red herrings, unexpected revelations);
**atmosphere** (cinematography, location, sound); **foreshadowing**. "Check your story against each one … any gap is a
chance to strengthen the suspense." Five types: mystery (what already happened), dramatic irony (audience knows more),
threat (imminent danger), emotional (a relationship/personal outcome), moral (dilemma with no clear right answer).

## STE_PROCEDURE
1. Before locking the script, score each of the 7 elements yes/no against the draft.
2. For each "no", add or change one line (not a new section).
3. Name which of the 5 suspense types the hook uses (usually mystery or dramatic irony).
4. Check the don'ts: tension resolved too early? over-explained? predictable? emotional stake missing?
5. Record the 7 yes/no marks in `episode.md`.

## AGENT_EXECUTION
`episode.md` → `Suspense check: characters ✓ conflict ✓ pacing ✓ stakes ✓ uncertainty ✗→L06 turn added ✓ atmosphere ✓ foreshadowing ✓ | type: dramatic irony`.
Map: characters → who "korang" is; conflict → the contradiction in frame 0; pacing → setup lengths; stakes →
three-stakes-layers; uncertainty → mid-story-expectation-break; atmosphere → light/surface choice; foreshadowing →
hitchcock-bomb / plant-and-payoff.

### Worked example
Topic: "Kenapa kedai dobi buka 24 jam" (illustrative).
- BEFORE draft: hook "Kedai dobi buka 24 jam" (no conflict), mechanism lines, end "Menarik kan?"
- AFTER check: conflict ✗ → frame 0 "Takde pekerja. Tetap untung RM3,000." (illustrative); foreshadowing ✗ → L02 shows the electricity meter in accent, paid off at L08 "Bil elektrik RM900 sebulan"; end text "Korang percaya mesin lebih dari orang?"

### Check
- Are all 7 elements marked yes after edits?
- Is the hook's suspense type named?
- Is any tension resolved before the payoff line?
