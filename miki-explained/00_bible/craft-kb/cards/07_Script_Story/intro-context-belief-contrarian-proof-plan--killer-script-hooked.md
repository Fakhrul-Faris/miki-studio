## CREATIVE_INTENT
"An intro hook framework that works every time, short form long form." Goal after click confirmation: "build a curiosity
loop… each line should make them want to go to the next line." Parts: (1) **immediate context** — "bluntly" state what
the video is about, so the viewer can opt in; (2) **common belief** — restate the conventional take, because it is
probably the viewer's belief and it "sets up the contrast"; (3) **contrarian take** — "contradicts that common belief and
this will stun them"; (4) and (5) in either order: **proof** for why to trust the new approach, and a **plan** — "an
ordered list or steps for how you're going to do it". Source intro: context ("today we're talking about writing killer
scripts…"), belief ("this is an art… one of the hardest things to learn"), contrarian ("there is a right answer… they all
run the exact same process"), plan ("the proven five-step framework"), proof ("I've done over a billion views").

## STE_PROCEDURE
1. Write L01 as blunt context: the topic in ≤ 15 words, matching frame-0 text.
2. Write the common belief the viewer likely holds, in their words.
3. Write the contrarian take that contradicts it in one line.
4. Add proof: one checkable fact or RM number supporting the take.
5. Add the plan: "N step je" (S16) or the question the video will answer.
6. Make each line end so the next line is needed.

## AGENT_EXECUTION
Script: L01 context + belief (can share a line), L02 contrarian + proof, L03 plan. Frame-0 text = belief vs take in ≤ 8
words. Shot list: belief row shows the familiar object as people see it; contrarian row changes its state on the turn word
("Tapi").

### Worked example
Topic: running a stall from home (illustrative).
- BEFORE: L01 "Hari ni saya nak share tips jual kuih." L02 "Ada tiga tips." L03 "Jom tengok."
- AFTER: L01 "Jual kuih dari rumah, ramai kata kena murah baru laku." (context + belief) L02 "Tapi naik 20 sen sebiji, 100
  biji sehari, dah RM20 lebih." (contrarian + proof: 100 × RM0.20) L03 "Kalau korang nak naik harga tanpa hilang
  customer, ni caranya. Tiga step je." (plan)

### Check
- Does L01 state the topic bluntly?
- Is the common belief stated before the contrarian take?
- Is the proof a fact/number, not a boast?
- Does L03 give a plan (N steps) or the open question?
