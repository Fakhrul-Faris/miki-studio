## CREATIVE_INTENT
Write what appears on screen alongside each spoken line. If a sentence has no clear visual, simplify or rewrite it —
the script is not done until every line can be drawn.

## STE_PROCEDURE
1. Draft the script as a two-column table: spoken line | what is on screen.
2. Fill the screen column for every line with a concrete object, screen or number, in ≤ 12 words.
3. If a screen cell needs a vague word ("concept", "icon", "graphic of"), mark the line blind.
4. Rewrite each blind line so it names something showable (an object, an action, an RM number).
5. If a blind line cannot be rewritten, cut it.
6. Re-read: each screen cell must differ from the previous one (a new setup or a state change).

## AGENT_EXECUTION
Add the screen column to the script block in `episode.md` (Script v1). The shot list copies it into "Setup and camera".
### Worked example
Topic: "Kenapa harga sama, untung kedai lain lain" (kedai runcit, illustrative).
- BEFORE: `"Pengurusan kos yang efisien sangat penting." | ??? (graphic of efficiency)` — blind.
- AFTER: `"Satu kotak air mineral, beli RM 18, jual RM 24." | macro: a shrink-wrapped carton, two price tags flip in
  on "18" and "24"`; `"Kedai sebelah beli RM 15." | same carton, the 18 tag slides off, a 15 tag in accent orange`.
### Check
- Does every line have a screen cell naming a concrete object, screen or number?
- Are there zero cells with "concept", "icon" or "graphic of"?
- Does each screen cell differ from the one before it?

## ADDENDUM — What Makes a Great Motion Design Script
Sharpens the test per line: "What is the animator going to show during this line?" — if you can't immediately
picture one clear, specific visual, the line isn't working. Adds a density limit: if one sentence needs three
different visuals, it is doing too much — split it so each idea gets room. Names three kinds of showable content a
line can be: a scenario to illustrate, a transformation to show, a comparison to visualise. Extra steps: (7) count
the visuals each line needs — more than one distinct visual idea (or more than ~2 setups' worth) means split the
line; (8) tag each screen cell as scenario / transformation / comparison — a cell that fits none is blind. Example
pair from the source: blind "our platform delivers exceptional value" vs. showable "watch three days of manual
reporting collapse into a single click."
