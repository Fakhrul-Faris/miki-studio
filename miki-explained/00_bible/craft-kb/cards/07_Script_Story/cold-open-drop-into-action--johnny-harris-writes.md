## METADATA
07_Script_Story | script + sound note | L01, frame 0

## CREATIVE_INTENT
"The first line is always the tricky one." Harris wants first lines that "drop you into action, that enliven the viewer's
senses with a surprising action or visual", often "look at this…". Not "I want to tell you the story of…", not "tell them
what you're going to tell them". Example: "It started with the murder of their prophet in Illinois", with the sound note
"gunshot, epic, suspenseful, slow-mo". "Hit them with emotion, tone, action, visual" so the viewer feels "we're in
something already, we're not ramping up to it."

## STE_PROCEDURE
1. Before you write L01, list the single most surprising action or visual in the story.
2. Start L01 with that action (agent + verb), or with "Tengok ni / Look at this" over it.
3. Delete any L01 that announces the topic ("Hari ni kita cerita…", "Let me tell you…").
4. Write the emotional tone of frame 0 in ≤ 4 words beside the line (e.g. "tense, quiet, close").
5. Make frame 0 already moving on that action (no ramp-up shot).
6. Use ramp-up openings only when the topic needs context first, and then ≤ 1 line.

## AGENT_EXECUTION
Script L01 + shot-list row 1: the "State change and events" cell holds the action happening at frame 0; add a tone tag.
### Worked example
Topic: a kedai bundle in Penang that buys stock by the bale (illustrative).
BEFORE L01: "Hari ni aku nak cerita pasal bisnes baju bundle."
AFTER L01: "Satu bal baju, RM800, dibelah — dan kedai tak tahu apa ada dalam tu." Frame 0: macro of a cutter slicing the bale strap, strap springing open; tone "tense, close, quiet".
### Check
- Does L01 contain an agent doing a visible action?
- Is there no topic announcement in L01?
- Is frame 0 already moving on that action?
- Is a tone tag written for frame 0?

## NOTES
- ⚠ Harris's "gunshot, slow-mo" is a dramatic SFX stinger; our SFX rule is sparse. Adapted: carry tone with the image and one subtle sound, never a stinger.
- Visual gaps: the Mormon cold-open visuals are only named, not described.
