## CREATIVE_INTENT
Once the concept is explained, move on; over-explaining confuses, or over-simplifies for an expert audience.

## STE_PROCEDURE
1. Mark the line where the analogy has made the point.
2. Delete any later line that only restates the analogy.
3. Limit one analogy to ≤ 2 lines (~ inferred from our word budget).
4. Return to the literal topic in the next line.

## AGENT_EXECUTION
In the script table, flag analogy lines; the critic checks no third analogy line exists.

### Worked example
BEFORE: "E-wallet macam tabung ayam. Duit masuk, tak bertambah. Tabung tak bagi faedah. Sama macam e-wallet, tak ada untung."
AFTER: "E-wallet macam tabung ayam. Simpan setahun, RM500 tetap RM500." → next line returns to the topic: "ASB pula, RM500 boleh jadi RM520." (illustrative)

### Check
- Does the analogy take ≤ 2 lines?
- Does the line after it return to the real topic?
- Is there no line that only repeats the analogy?
