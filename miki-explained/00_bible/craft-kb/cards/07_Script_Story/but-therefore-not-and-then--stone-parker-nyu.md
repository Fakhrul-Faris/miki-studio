## METADATA

## CREATIVE_INTENT
Take the beats of your outline. If the words "and then" belong between two beats, "you've got something pretty boring".
Between every beat there should be either **"therefore"** or **"but"**: this happens, therefore this happens, but this
happens, therefore this happens. That gives causation between beats — "that's a story". South Park literally writes the
words out between the beats to check.

## STE_PROCEDURE
1. List the script lines (or beats) one per row.
2. Between each pair, write the joining word literally: "but", "therefore" or "and then".
3. Mark every "and then" join as a failure.
4. Rewrite a failed beat so it is caused by the previous beat (therefore) or complicates it (but).
5. Cut the beat if neither rewrite works.
6. Check that the joins alternate somewhat; ~1 "but" for every 1–2 "therefore" (~ inferred, source gives no ratio).
7. Re-read the joins in sequence; the chain must read as cause and complication, end to end.

## AGENT_EXECUTION
Add a join column to the script table in `episode.md` while drafting (removed before the user sees the final):
`| L | Caption | join to next |`. For S16 how-tos, steps naturally read "and then" (step 1, step 2…); fix by making each
step the answer to a problem the previous step leaves ("screenshot dulu → **but** kedai boleh tukar harga asal →
**therefore** compare bila sale start"). Malay joins: "tapi" (but), "sebab tu / jadi" (therefore).

### Worked example
Topic: a laundry shop owner pricing per kg (illustrative numbers).
BEFORE (and-then chain): L04 "Step satu, timbang baju." → and then → L05 "Step dua, kira harga." → and then →
L06 "Step tiga, bagi resit."
AFTER: L04 "Step satu, timbang baju depan pelanggan." → **but** → L05 "Tapi timbang je tak cukup, pelanggan still
rasa mahal." → **therefore** → L06 "Jadi, tulis RM4 sekilo besar-besar kat kaunter." → **but** → L07 "Tapi baju tebal
selimut? Lagi berat, lagi untung RM12."

### Check
- Is every join between lines "but" or "therefore" (tapi / jadi / sebab tu)?
- Does no join read naturally as "and then"?
- Do steps in a how-to each solve a problem raised by the line before?
- Is there at least one "but" after the mechanism starts (not only in L02)?

## ADDENDUM — How To Become A Master Storyteller
Reframes the same mechanism as "the dance" between context and conflict: conflicts **open** loops in the brain,
context **closes** them — Hook/Open loop lines are the conflict, Mechanism lines are the context, then a new "tapi"
reopens. Gives a density anchor from the source's own Stanley Cup example: **4** "but" conflict loops in the first
**30 s** (its structure: status fact → "but the real question is how" → near-discontinuation → "but" a resale
sellout → "but it gets even better"). Scaled to a 55–90 s episode, that is roughly one "tapi/but" every ~7–8 s — use
as a loose density check alongside this card's own alternation check, not a hard rule (source gives no formal ratio
either). "And then" failure mode restated as "piling on detail after detail." Adds head-fake devices for the join
itself: "but the real question is…", "but it gets even better…" → Malay "tapi soalannya…", "tapi ada lagi best…".
Build step: count the "but/tapi" joins in the first 30 s of the timed script and aim for ~3–4.
