## METADATA
07_Script_Story | general | Script body order

## CREATIVE_INTENT
After the intro, viewers compare each point with what they already know; "the first point in the body… has to be amazing";
if it repeats something known "immediately they will get disappointed". But the "cheat code… is to put your second best
body point in that first slot". "Human brains work in patterns": two amazing things, "especially if the second thing is
better than the first", make a pattern so "they have to stay to see the third"; best-first then weaker "trains the viewer
subconsciously that the value will be diminishing". Albums put the banger at track 3 or 4, never first. Order: "second
best point first, your best point second, your third best third and so on" — by "shock value, novelty and uniqueness".

## STE_PROCEDURE
1. Rank the body points by novelty/shock (1 = best).
2. Place rank 2 first, rank 1 second, then 3, 4, 5.
3. If the steps must run in real-world order, keep that order.
4. Then strengthen the payoff of the 2nd step so value still rises from step 1 to step 2.
5. Make sure the first body point is not common knowledge.

## AGENT_EXECUTION
In the Outline, add `rank:` per point and the chosen order. Script L04–L08 follow it. In S16 sequential how-tos, give
step 2 the RM number or the surprising rule, step 1 a solid but smaller one.

### Worked example
Topic: 3 ways a kedai makan cuts waste (illustrative). Ranked: A) weigh leftover rice each night → found 4 kg/day (best);
B) smaller default portions with free top-up (2nd); C) label containers by date (3rd).
- BEFORE: A, B, C (best first, then declining).
- AFTER: B → A → C. L04 B: "Nasi kurang sikit, tambah free." L06 A: "Timbang nasi lebih tiap malam: 4 kilo sehari
  dibuang." L08 C.

### Check
- Is the first body point the second-strongest, and not common knowledge?
- Is the strongest point in slot 2?
- If the order is forced by sequence, does step 2's payoff still beat step 1's?
