## METADATA
07_Script_Story | general | script L03–L05

## CREATIVE_INTENT
"Before introducing the central mystery or conflict, the script establishes the setting, key players, and technical
mechanics" — e.g. explaining how a cipher works in *The Unbreakable Kryptos Code* before examining the unsolved fourth
passage.

## STE_PROCEDURE
1. Before you write the twist or step, list what the viewer must know to follow it.
2. Keep only the one mechanic the payoff depends on.
3. Teach it in ≤ 2 lines, with one showable object.
4. Then show the twist, using the same object.

## AGENT_EXECUTION
Script L03–L04 = context; L05+ = the conflict. Shot list: the context object is reused in the conflict setup.

### Worked example
Topic: why "beli 2 percuma 1" can cost more than a plain discount (plain arithmetic, illustrative).
- BEFORE: L03 jumps straight to "Promo ni sebenarnya tak untung."
- AFTER: L03 "Satu botol RM9. Beli dua, dapat tiga: RM18 untuk tiga botol." L04 "Tu RM6 sebotol." L05 "Tapi kedai
  sebelah jual RM5.50 sebotol, tak payah beli tiga."

### Check
- Is only the one needed mechanic taught?
- Is it ≤ 2 lines, with an object?
- Does the conflict reuse that object?
