## CREATIVE_INTENT
The studio (based in the Philippines) writes coherent English, but it may carry grammar errors and "it's not localized in
whatever market the client wants to target" — UK and US word choices differ. So whenever they write the script they
**hire a copywriter to proofread and localise it** for the target market.

## STE_PROCEDURE
1. Before the voice text, mark every word a Malaysian 18–34 viewer wouldn't say aloud (formal BM, textbook English).
2. Replace each with the casual spoken form (korang, je, tu, English loanwords as spoken).
3. Keep money as Malaysians say it ("RM5" read as "lima ringgit").
4. Send the marked lines to the user (native speaker) for a final pass before recording.

## AGENT_EXECUTION
Add a "loc" column to the script table with the original → localised word swaps; the user's corrections are logged and
fed back into future scripts.

### Worked example
BEFORE: "Anda boleh menjimatkan wang dengan membandingkan harga seunit."
AFTER: "Korang boleh jimat — tengok harga seunit, bukan harga pek." 

### Check
- Has every formal/textbook word been swapped for the spoken form?
- Are RM amounts written as they're said?
- Did the user (native) review before recording?
