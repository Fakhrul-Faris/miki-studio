## METADATA
07_Script_Story | TED-Ed (Dan Gilbert talk analysed) | open loop → mechanism turn

## CREATIVE_INTENT
Gilbert asks the audience to imagine winning the lottery versus becoming paraplegic and pick one; shows the "expected"
data ("I made these up"), then the real data: a year later both groups are equally happy. "You failed the pop quiz."
This puts the viewer in a "knowledge gap" — "there's more information you need". He fills it by naming the cause
("impact bias"): "by putting a name on it… the mystery starts to become more believable", and curiosity "is now burning
more brightly" for the big idea.

## STE_PROCEDURE
1. Pick a fact where the common guess is clearly wrong (verified in the claim ledger).
2. Ask the viewer to choose or guess between two options in one line.
3. Show the guess they probably made, briefly (~1 s), as the "expected" answer.
4. Replace it with the real number on its word.
5. In the next line, give the cause a short name (≤ 3 words).
6. Only then explain how the named cause works.

## AGENT_EXECUTION
Script: question line → reveal line → naming line → mechanism. Shot list: the "expected" value appears on the hero
(a price tag, a counter) and is replaced (slide/grow, ~0.4 s, never a pop) by the real value in the accent colour on the
number word. The name appears as on-screen text ≤ 3 words.
### Worked example
Topic: buying a RM5,000 laptop on 0 % instalment versus cash (illustrative; plain arithmetic, no fees assumed).
BEFORE: "Ramai tak tahu ansuran 0 % kadang-kadang ada kos tersembunyi."
AFTER
- "Cash RM5,000, atau ansuran RM417 sebulan, 12 bulan. Mana lagi murah?"
- "Ramai pilih ansuran." (expected tag: "jimat")
- "Kira: 417 kali 12… RM5,004." (real number in accent)
- "Nama dia: harga bulat-bulat." (name)
- next line explains the rounding up of RM416.67 to RM417.
### Check
- Is the contradicting fact verified in the claim ledger?
- Does the viewer get a two-option question before the reveal?
- Does the real number land on its spoken word, replacing the expected one smoothly?
- Is the cause named in ≤ 3 words before it is explained?

## NOTES
- Visual gaps: the talk's slides (made-up versus real happiness charts) are only described in speech.
- Real instalment plans can carry fees; the episode must use verified plan terms — the example only shows the division
  rounding, which is plain arithmetic.
