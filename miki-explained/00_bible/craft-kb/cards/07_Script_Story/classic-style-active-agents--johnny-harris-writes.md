## METADATA
07_Script_Story | Steven Pinker, *The Sense of Style* (classic style) | every script line

## CREATIVE_INTENT
Harris's "entire Bible of writing": an "obsessive focus on active, visual language". Say "they fled", not "leading to the
migration of 6,000 Mormons"; "migration of" is a concept, "they fled" is people doing a thing "our brains can see".
Replace abstract nouns ("globalization") with an agent acting ("America sends Ford to Japan"). The pillars: visual, plain,
clear, concrete. The Economist is the model: "this person did something", in plain, quippy terms.

## STE_PROCEDURE
1. For each line, underline the grammatical subject. It must be a person, shop, object or money that acts.
2. Replace every abstract noun ending -tion/-isme/-an (migration, globalisasi, pengurusan) with agent + verb.
3. Keep one agent and one verb per line where possible.
4. Ask "can a camera see this?"; if no, rewrite until yes.
5. Prefer the plainer word when two mean the same.
6. Keep numbers attached to the agent ("kedai ni bayar RM1,200"), not floating ("kos sebanyak RM1,200").

## AGENT_EXECUTION
Run on the script before showing it. In the shot list, the agent of each line becomes the hero object of that setup and the
verb becomes the state change.
### Worked example
Topic: why a kopitiam in Ipoh raised its kopi price (illustrative).
BEFORE: "Peningkatan kos operasi menyebabkan pelarasan harga."
AFTER: "Pembekal naikkan harga susu pekat. Kopitiam ni naikkan kopi 20 sen." → shot: macro tin of condensed milk, price sticker peels off and a new one slides on; cup price tag ticks RM2.20 → RM2.40.
### Check
- Does every line have a concrete acting subject?
- Are there zero abstract -tion/-isme nouns as subjects?
- Can each line be shown literally by one object changing state?
- Is every RM number attached to the agent that pays or earns it?

## NOTES
- Bahasa Melayu passive (di- verbs) is natural; allowed if the agent is still named ("disaman oleh KPDN") — prefer active.
- No visual gaps; purely verbal.
