## METADATA
07_Script_Story | Google Docs two-column script, keyboard macro | script + shot list together

## CREATIVE_INTENT
Harris writes prose in the left column, presses Tab and "codes" the visuals in the right column, "choreographing visuals
that dance with the prose". "Every sentence or two has a new row" with its own direction; "every word must pair with a
motion or an action in the animation." He writes to "my future animator", naming how it could be built, and pastes
annotated screenshot references. A macro (Alt+A) makes an item bold, red and a checkbox in ~0.01 s: red = a visual asset
that must be collected, so he can code without touching the mouse.

## STE_PROCEDURE
1. Before writing line 2, write line 1's visual in the next column.
2. Start a new row every 1–2 sentences (ours: every line, ≤ ~4 s).
3. In the visual cell, name the hero, the state change and the word it lands on.
4. Mark every asset not yet in hand as "☐ NEED: <asset>" (our red checkbox).
5. Paste or link one reference per row where the look is not obvious.
6. Write the cell as instructions to the builder (props, timings), not as prose.
7. Before showing the script, count open "☐ NEED" items; list them under the table.

## AGENT_EXECUTION
Draft Script v1 and Shot list v1 as one table: `| L | Line | Setup and camera | State change and events (on word) | assets ☐ | cards |`, then split into RECIPE-D's separate script and shot-list tables for the user gate.
### Worked example
Topic: a phone repair kiosk in Low Yat pricing a screen swap (numbers illustrative).
BEFORE: script written alone; shot list made later, with L04 "Kos skrin RM180" getting a generic phone close-up.
AFTER: | L04 | "Skrin baru, kedai beli RM180." | macro, low angle on the cracked phone, top light | on "RM180": cracked glass lifts off, new panel slides in with a price tag; counter 0→180 | ☐ NEED: replacement panel GLB | cards: … |
### Check
- Does every line have its visual cell written in the same pass?
- Does each visual cell name the word its event lands on?
- Are missing assets marked ☐ and listed?

## ADDENDUM — What Makes a Great Motion Design Script
Source: "Explainer Visual Metaphors & Art Direction Critiques/What Makes a Great Motion Design Script.md" (blog, section "The Handoff"; no timestamps)

| Source | Value / rule |
|---|---|
| Dan Neale (Motion Story) | Deliverable = two-column document, voiceover left, visual direction right; each row = one scene; the animator reads across. |
| Dan Neale | Readiness gate: if the visual column is vague ("show the platform"), the script is not ready. Specific = "animated dashboard showing lead scores updating in real time as a sales rep's daily pipeline builds". |
| Dan Neale | Why: bad scripts create expensive revisions in animation, "the most time-consuming phase to change". |

Extra step: gate before the shot list — scan the visual column for vague verbs ("show", "display", "graphic of") with
no object, state and cue word; any hit = script not ready, return to script v2.
