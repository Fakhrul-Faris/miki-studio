## METADATA
08_Edit_Pacing | general (StudioBinder) | shot-list "Setup and camera"

## CREATIVE_INTENT
"Films are made up of sequences, sequences of scenes, scenes of shots." "Shot choices help establish the rhythm, tone
and meaning of a scene"; choosing the most aesthetically and dramatically valuable size "should be the highest
priority for both a director and a DP". The ladder: establishing → master → wide → full (head to toe; physicality,
"in all their glory") → medium full / cowboy (head to below waist; confident, confrontational) → medium (above waist,
neutral) → medium close-up (mid-chest up) → close-up → extreme close-up / insert.

## STE_PROCEDURE
1. Map the ladder to the hero object: EST = the place; WS = object small in its world; FS = whole object edge to edge; MS = object + its immediate context; MCU = the working part + its result; CU = one face/side; ECU/insert = one crucial detail.
2. Tag each row with one size code (EST/WS/FS/MS/MCU/CU/ECU).
3. Before locking, make sure no two adjacent rows share a size.
4. Put the tightest sizes (CU/ECU) on the lines with the key number or decision.
5. Use FS when the line is about the whole object's form ("the full object in all its glory").

## AGENT_EXECUTION
Shot-list Setup cell starts with the code: `MCU · macro 85 mm, low angle on the card reader`. Board check: count sizes;
flag 3+ of the same size in the episode's first 5 rows.

### Worked example
Topic: "Mesin layan diri dobi — RM5 untuk apa?" (illustrative).
- BEFORE: rows 1–5 all "macro of the washing machine".
- AFTER: 1 `ECU · coin slot with an RM5 token` → 2 `FS · whole machine, front` → 3 `EST · row of machines in a night shop` → 4 `MCU · drum + display counting 30 min` → 5 `CU · the display "RM5 = 30 min"` (accent).

### Check
- Does every row carry a size code?
- Are adjacent sizes different?
- Is the key number on a CU/ECU?

## NOTES
- Cowboy shot (confrontation, "when weapons might be drawn") is people-only; not used in Style D.
