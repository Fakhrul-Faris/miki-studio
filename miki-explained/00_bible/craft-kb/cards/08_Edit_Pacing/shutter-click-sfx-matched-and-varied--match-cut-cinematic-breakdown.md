## CREATIVE_INTENT
"Without sound, a match cut just falls so flat. Sound is like 80% of what makes a good match cut." Quick frames need a quick-frame sound — a camera shutter or mechanical click — one per cut. Using the exact same click on every cut in a long run "would feel very repetitive", so the source either pitches the one click up/down between cuts or swaps in a different texture (a fuzzy white-noise whoosh) for variety.

## STE_PROCEDURE
1. Before scoring a match-cut run, confirm it is a run the house SFX-restraint rule allows (the run IS the content, not decoration).
2. Put one short click/shutter/mechanical sound on every cut in the run, timed exactly to the cut frame.
3. If the run is long (4+ cuts), do not repeat the identical sound on every cut.
4. Vary it by pitch-shifting the same sample up/down between cuts, OR swap to a different short texture every few cuts.
5. Keep each sound under the cut's own duration; never let it ring into the next cut.

## AGENT_EXECUTION
Shot-list "cards" column: tag the run with this card once; frame-brief for each cut in the run adds one SFX cue in "Handover" (e.g. "click, pitched +2 from previous"). In the audio pass, alternate 2–3 short click/shutter samples across the run instead of looping one file.

### Worked example
Topic: a resit (receipt) total counting up through 5 items (illustrative RM values).
BEFORE: 5 quick item-add cuts, silent except the music bed.
AFTER: `| 6 | "Item satu... dua... tiga..." | locked receipt macro framing, line adds per cut | each line-add gets one click, pitched up slightly each time | shutter-click-sfx-matched-and-varied |`

### Check
- Does every cut in the run have exactly one short sound on it, on-frame?
- If the run has 4+ cuts, is no single sample repeated identically more than twice in a row?
- Is this run one the SFX-restraint rule actually allows (content beat, not decoration)?
