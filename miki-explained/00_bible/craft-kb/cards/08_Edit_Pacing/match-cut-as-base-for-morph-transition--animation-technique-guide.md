## CREATIVE_INTENT
"A match cut does have the blurry edge" with a full shape transition, depending on how much you put on top. "If you
are wanting to create a fully formed shape morph transition, starting with a match cut is a great place to start, and
then you can just add elements on top and make it more intricate and more connected between the two scenes."

## STE_PROCEDURE
1. Build the plain match cut first (shared shape or motion) and confirm it reads.
2. Add one bridging element that starts in A and ends in B (e.g., a shape that grows across the cut).
3. Add one secondary element that reacts to the bridge.
4. Stop when the join reads as one move; remove any element that doesn't connect A to B.

## AGENT_EXECUTION
Shot list: write the base match first ("shape: round coin → round dial"), then list the add-ons. raea: base = cut on
the word; add-ons = meshes animated with clamped `interpolate` spanning the cut frame in both compositions.

### Worked example
Topic: "Beli guna ansuran 3 bulan — tarikh yang korang kena ingat" (no rate or fee claims).
- BEFORE: cut from a phone checkout screen to a calendar.
- AFTER: base match: round "Pay" button → round calendar date circle, same screen spot. Add-on: the button's accent ring expands across the cut into the circle around "15 haribulan". Secondary: three more date circles light up in sequence on "tiga bulan".

### Check
- Does the base match cut work on its own?
- Does each added element connect A to B?
- Is there no element that is decoration only?
