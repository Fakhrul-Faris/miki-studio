## METADATA
08_Edit_Pacing | short-form creator tactics | script order + timings check

## CREATIVE_INTENT
Every piece of content has "a timer counting down before it explodes": ~4 s on short form, ~1–2 min on YouTube.
Anything after the viewer leaves "might as well be a black screen". Give a small hit of value in the hook or right
after it; don't bury your best stuff. Then run a **value loop** like the curiosity loop: context → immediate value →
context → immediate value. If the first hit is unique and helpful, viewers stay long enough for the second. You aren't
optimising for full completion (super-fans do that); you're earning ~30 more seconds at a time.

## STE_PROCEDURE
1. Before you lock the script, mark the first line that gives the viewer something usable (a number, a step, a check).
2. If that line starts after ~4 s, move it up or merge it into the hook.
3. After each value line, follow with one context line, then the next value line.
4. Put the strongest step or number first among equal steps, not last.
5. After voice timings arrive, confirm the first value word lands ≤ ~4 s.

## AGENT_EXECUTION
Mark value lines with "V" in the script table. In S16 how-tos the first step or the RM "why it matters" number can sit in
L02–L03. Shot list: the first value word gets an event (counter starts, tag flips).

### Worked example
Topic: comparing pack sizes at a pasaraya (how-to).
BEFORE: L01 "Ramai orang suka beli pek besar." L02 "Sebab rasa lebih jimat." L03 "Tapi betul ke?" L04 "Hari ni saya
tunjuk 3 cara…" (first usable tip at ~12 s).
AFTER: L01 "Pek besar tak semestinya lagi murah." L02 "Tengok harga per 100g, bukan harga tag." (value at ~3 s) L03
"Pek 500g RM8.50, so RM1.70 per 100g. Pek 200g RM3.20, so RM1.60." (arithmetic check: 8.50÷5 = 1.70; 3.20÷2 = 1.60).

### Check
- Does the first usable fact land within ~4 s of audio?
- Does every context line lead straight into another value line?
- Is the best step/number not saved for the end?

## NOTES
- The 4 s / 1–2 min timers are the creator's rule of thumb, not measured data.
