## CREATIVE_INTENT
"Withhold the payoff: cut away before a tense moment resolves, then return to it later, leaving the audience on edge in
between." "Don't resolve tension too quickly. Let the audience sit with uncertainty."

## STE_PROCEDURE
1. Find the moment that resolves the hook (counter stops, box opens, total shows).
2. Start it on screen early; cut away one beat before it resolves (counter still rolling).
3. Fill the gap with the mechanism lines.
4. Return with the identical framing and finish the moment on the payoff word.
5. Keep the gap ≤ ~30 s so the viewer still remembers it (`~`).

## AGENT_EXECUTION
Shot-list: tag the early row `withheld → row N` and the return row `resolve ← row M`; same camera pose in both.

### Worked example
Topic: "Berapa sebenarnya kos sebiji burger RM6?" (illustrative).
- BEFORE: `| 2 | "Kos dia…RM4.20" | counter shows RM4.20 immediately |`
- AFTER: `| 2 | "Burger RM6. Kos dia berapa?" | macro receipt, cost counter rolls RM0.00 → RM2.?? and still rolling | cut away on "berapa" | withheld → 9 |` … `| 9 | "Kos semua: RM4.20. Untung RM1.80." | same receipt framing, counter resumes and stops at RM4.20 on the word | resolve ← 2 |`

### Check
- Is the moment started on screen and left unresolved?
- Does the return reuse the same framing?
- Is the gap short enough to be remembered?
