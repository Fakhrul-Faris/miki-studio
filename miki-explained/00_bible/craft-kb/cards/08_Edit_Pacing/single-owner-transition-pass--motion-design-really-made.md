## METADATA
08_Edit_Pacing | general (studio compile role) | shot list

## CREATIVE_INTENT
Animation is split by specialty (character / typography / motion graphics), and **one person compiles everything and is
responsible for the transitions**: "is it going to be just a cut or is the transition going to morph". Transitions are
judged as one system by one owner, not left to each shot's maker.

## STE_PROCEDURE
1. After setups exist, list every join in order (row n → row n+1).
2. For each join choose one: hard cut on the word, object morph, or camera flight through a shared object.
3. Write which scene object carries each morph or flight.
4. Check the run: no more than ~2 identical join types in a row (`~`).
5. Reject any join that uses a generic effect (wipe, flash, dissolve, whip).

## AGENT_EXECUTION
Add a `join →` column to the shot list (`cut on "untung"` / `morph: coin → pie slice` / `flight through receipt slot`).
Do this pass in one sitting across the whole film.

### Worked example
BEFORE: joins chosen shot by shot; four flights in a row, one crossfade.
AFTER (pasar malam profit, illustrative): `1→2 cut on "tapi"` · `2→3 morph: price tag RM3.50 → bar in chart` ·
`3→4 flight through the cash box slot` · `4→5 cut on "untung"`; crossfade removed.

### Check
- Does every join have a type and (for morphs/flights) a named carrier object?
- Was the pass done across the whole film at once?
- Are generic effects absent?

## NOTES
- Studio-only practices not carded: single storyboard artist after a team brainstorm (coherence), style frames split by artist specialty vs frame range (specialty worked better), outsourced sound design — single-agent pipeline makes them moot.
