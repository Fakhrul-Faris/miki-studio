## CREATIVE_INTENT
Clichés "say basically what we want them to. But they can be better. Loads better." Professional illustrators start
with a big, messy chart: separate the words of the message, find synonyms and associated words and phrases for each,
then draw what each makes you think of. The source example: "improving your intelligence" usually gets a lightbulb or
a brain; the chart opens up growth, feeding, nurturing, a plant.

## STE_PROCEDURE
1. Before choosing any image, write the line's message and split it into separate words.
2. For each word, list 5+ synonyms, associations and phrases (~).
3. Next to each, note the concrete object it brings to mind.
4. Cross out the first, most obvious image (the cliché).
5. Prefer objects the episode's business really owns or uses.
6. Keep 2–3 candidates for the merge step (see merge card).

## AGENT_EXECUTION
Frame brief: add a mini chart under **Idea**: `word → associations → objects`. "Not generic because" must name the
cliché rejected. Run on literal nouns first: if a literal object shows the line, stop there (house rule).
### Worked example
Line: "Simpan duit kecemasan, tiga bulan belanja." (everyday money; abstract "safety").
- BEFORE: piggy bank on a table (cliché).
- AFTER chart: "kecemasan" → bocor, banjir, payung, tayar pancit → spare tyre, umbrella; "tiga bulan" → calendar, 3
  envelopes; "belanja" → receipt, grocery bag. Candidates: spare tyre (a backup you hope not to use), 3 envelopes.
  Literal check: the line is about money set aside for 3 months → choose 3 labelled envelopes on the shelf (literal), and
  keep the spare-tyre idea only if the line itself says "tayar spare".
### Check
- Did you write associations for every key word before choosing?
- Is the chosen image something other than the first cliché?
- Did a literal object get first refusal?
