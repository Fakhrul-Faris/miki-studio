06_Art_Direction | film production design | board check + art-direction lines

## CREATIVE_INTENT
Burton made films with many different production designers and cinematographers; "the only constant is Burton
himself". Even films he only concepted read as his. Advice: don't copy the style, copy the **holistic approach to
world building** — environments have massive storytelling value, and set design "doesn't require a huge budget, just a
clear vision". Describe the sets in detail in your scripts.

## STE_PROCEDURE
1. Before building, write the episode's vision as ≤ 5 rules (light, palette, materials, motion, what bends).
2. Give the same rules to every builder (3D scene, UI screens, captions, sound).
3. Describe each set in detail in the shot list, not "a shop".
4. At board check, test every still against all rules; fix outliers at the source.

## AGENT_EXECUTION
Art direction five lines = the vision; paste them at the top of each sub-build brief (raea scene, HyperFrames/UI
screens). Board check adds: "Could any still be from a different video?" A UI screen with its own palette or a setup
with flat light fails.
### Worked example
Topic: "Cara buat invois guna phone dalam 3 step" (UI-heavy, ~80 % screens; illustrative).
- BEFORE: phone UI screens built in a bright white SaaS look; the 3D setups in Style D dark room — two videos stitched.
- AFTER: vision rules applied to the UI too: dark UI theme, the same single brand accent on the active field only,
  screens lit as an emissive phone in the dark room with bloom, the same eased 0.4 s grow-in. Board check: all 12
  stills pass "same video" test.
### Check
- Are the vision rules written down and given to every sub-build?
- Does every still (3D and UI) pass every rule?
- Is each set described specifically in the shot list?
