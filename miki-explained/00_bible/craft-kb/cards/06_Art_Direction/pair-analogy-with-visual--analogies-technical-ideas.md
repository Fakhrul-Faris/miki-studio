## METADATA

## CREATIVE_INTENT
Accompany the metaphor with a visual: a diagram of a house next to a software process "helps solidify the comparison".

## STE_PROCEDURE
1. Before briefing, name the analogy object and the real object it stands for.
2. Show the analogy object as the hero on the analogy word.
3. Join it to the real object with an object morph or a camera flight, not a split screen.
4. Put the accent only on the mapped part the line names.

## AGENT_EXECUTION
Frame brief fields: Idea = "X is like Y"; Decision = morph Y → X on the word; Moves = morph ~0.4–0.8 s eased in-out;
Handover = the real object, same framing. raea: no special prop; morph between two GLB models by scale/opacity cross,
per the raea-bevy animation file.

### Worked example
Topic: e-wallet balance like a tabung ayam (illustrative).
BEFORE: split screen, left a phone app, right a cartoon piggy bank, labels "A" and "B".
AFTER: Ref tabung ayam macro on a kitchen table → Idea "baki e-wallet = tabung" → Decision the tabung morphs into the
phone on "e-wallet", balance RM500 in accent → Eye on the coin slot / balance number → Not generic because the slot
becomes the balance digits.

### Check
- Is there one hero on screen at a time (no side-by-side slide)?
- Does the analogy object appear on the analogy word?
- Is the accent only on the mapped part?
