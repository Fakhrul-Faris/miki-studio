## METADATA
06_Art_Direction | general (live-action lighting, tool-agnostic) | shot-list (light-motivation column, planned across rows)

## CREATIVE_INTENT
A single shot's light motivation (what in the scene would realistically be casting it) can look like the "wrong"
choice in isolation, yet be exactly right once you see it as one step in a sequence that is building toward a later
beat — e.g. lighting a character more frontally only makes sense once you know they're about to turn and reveal an
off-camera source the audience hasn't seen yet. The motivation for one shot is sometimes "what the story needs this
shot to set up," not just "what's physically in this shot."

## STE_PROCEDURE
1. Before lighting the first setup of a run, read ahead to the beat it's building toward.
2. Decide the light motivation for the whole run first (one sentence: "these 3 setups build toward the reveal on L06").
3. Only then light each setup, checking it against that whole-run decision, not only against itself.
4. If a single setup's motivation looks odd on its own, confirm it reads correctly once played in sequence before changing it.

## AGENT_EXECUTION
Add a "light plan" line above the shot-list rows it covers in `episode.md` (e.g. "L04–L06: key stays dim and off the
hero until L06's reveal, where it snaps to the accent"). Each row's "State change and events" column then references
that plan instead of restating it. Build/preview the run together (not single stills) before judging any one setup's light.

### Worked example
Topic: a kedai runcit's hidden extra charge on a receipt (illustrative numbers).
BEFORE: L04 (receipt close-up) lit flat and even because "that's what the object needs" in isolation.
AFTER: light plan written above L04–L06 — "L04–L05 keep the extra line dim/unlit (the viewer hasn't noticed it yet);
L06's key swings onto that one line as the voice says the number, in the accent." L04 on its own now looks
under-lit, but it is correct because it is part of the planned L04–L06 reveal.

### Check
- Is there a one-line light plan covering the run of setups, written before any one of them is lit?
- Does each setup's light motivation reference that plan rather than only itself?
- Was a setup that looks "wrong" alone re-checked against the sequence before being changed?
