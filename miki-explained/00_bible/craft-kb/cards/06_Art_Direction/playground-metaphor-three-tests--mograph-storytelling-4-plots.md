## METADATA
06_Art_Direction | general | frame brief (Idea, Decision) + script check

## CREATIVE_INTENT
"If the idea is abstract, set the story in a world your buyer already knows." "A board game teaches money faster than a
finance class." A metaphor works when: "Your buyer already knows its rules. It lasts the whole video. And it can change
when your product arrives." EU tax and customs explains VAT carousel fraud with an actual carousel and ends with it
stopping: "Turn your buyer's problem into a machine they've ridden, then stop the machine. If the metaphor can't be
stopped, it can't show your fix." Alation keeps its stadium to the end: "If the metaphor drops away halfway, the proof
feels pasted in." Recruit CRM: a story spanning months → "draw it as a trip with a destination. If the destination isn't
a number your buyer cares about, change it." MSD: "give it one shape that grows. If the shape never changes, it's a logo."
Labuan IBFC: one familiar symbol per promise (magnifying glass = transparency, shield = security); "more than 3 symbols,
the list is too long for one video." eSentire: "If you sell protection, draw the territory you watch."

## STE_PROCEDURE
1. Before choosing a metaphor, confirm the line is a metaphor or there is no literal object.
2. Pick a world whose rules a Malaysian 12-year-old already knows (pasar malam, kereta api, congkak).
3. Test 1: can the viewer predict how this world behaves without explanation?
4. Test 2: can it carry every setup from frame 0 to the end question?
5. Test 3: can it change or stop on the fix word?
6. Drop the metaphor if any test fails; go back to a literal object.
7. For a months-long story, make it a trip whose destination is an RM number.
8. Cap symbols at 3, one per promise.

## AGENT_EXECUTION
Frame brief: `Idea:` the world; `Decision:` the change it makes on the fix word (stops, fills, arrives); `Not generic
because:` the world's rule matches the mechanism. Write the three test answers in the brief's NOTES. Build the world as a
real macro object set (a toy, a game board on a table) to stay inside Style D.

### Worked example
Line (a metaphor in the script): "Ansuran BNPL ni macam kereta api — satu gerabak tambah, tak nampak hujung."
- BEFORE: generic credit-card icons multiplying.
- AFTER: a toy train on a kitchen table; each RM50 instalment hooks on a carriage (known rules: carriages couple; lasts:
  every later setup adds carriages; change: on "berhenti" the train halts and the carriages count up — 6 × RM50 = RM300).
  End question: "Berapa gerabak korang tengah tarik?"

### Check
- Is the line itself a metaphor (house rule) or is there truly no literal object?
- Does the world pass all 3 tests?
- Does the destination/endpoint carry an RM number?
- Are there ≤ 3 symbols?
