## CREATIVE_INTENT
Give the image "one extra little push": what stories can you see in it, what message does it send? If you stumble on a
good one and it fits your story, use it — "all because you didn't settle for a boring, clichéd metaphor".

## STE_PROCEDURE
1. Before locking the setup, list 2–3 further stories the chosen image suggests.
2. Keep only one that matches a later script line.
3. Plan it as a state change of the same object in a later setup.
4. Drop any layer that adds a claim the script doesn't make.

## AGENT_EXECUTION
Frame brief **Moves / Handover**: "same object carries L0x: <state>". Shot list: later row reuses the object with a
new state, joining setups with an object morph or camera flight.
### Worked example
Hero (from merge card): cup whose surface reads as a clock.
- BEFORE: the cup appears in L04 only; L06 ("Kira masa, harga naik RM 1") cuts to a new price board.
- AFTER: L06 reuses the cup: the "clock" hand reaches the cup's rim and two 50 sen coins rise out of the coffee in accent
  on "RM 1" — same object, next story (time spent = price added).
### Check
- Does the extra layer match a real line of the script?
- Is it the same object in a new state, not a new metaphor?
- Does it add no unscripted claim?
