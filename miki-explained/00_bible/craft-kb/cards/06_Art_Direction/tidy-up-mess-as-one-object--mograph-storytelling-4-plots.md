## CREATIVE_INTENT
"If your buyer lives with the mess, draw the mess, then clear it on screen." A before-and-after garage photo "sells the
shelving. Nobody asks for the bracket specs." The Tidy-Up is "the buyer's mess drawn first, then cleared in one continuous
move." Wirepas draws traditional tracking as **tangled wires**, then takes them away and lands on one word, "FREEDOM".
"Pick one object that stands for your buyer's old way, and remove it on screen. If the mess has no single picture, the
tidy-up won't land." Further moves: name 2 tools the buyer keeps after the tidy-up so it doesn't look like rip-and-replace
(airfocus: Jira and Azure DevOps stay connected); if the mess is distance, draw it on a map then connect it — "If the
lines don't meet at your product, redraw them" (Jotform); show every separate tool, then merge them in one move — "If they
merge off screen, 'integrated' is just a word" (BioStar 2).

## STE_PROCEDURE
1. Before planning setups, name the one object that stands for the old way (≤ 3 words).
2. If you can't name one, don't use Tidy-Up; pick another plot.
3. Show the mess object first, in the opening setups.
4. Clear it in one continuous on-screen move on the fix word; never off screen.
5. Name what the viewer keeps (≤ 2 things) so the clean state isn't a full replacement.
6. If the mess is distance, draw it on a map and make the lines meet at the fix.
7. Land on one word or number for the clean state.

## AGENT_EXECUTION
Shot list: row 1–2 `State change` = the mess object (e.g. "a fist of 40 loose receipts on the counter"); the fix row =
"receipts slide off into one folder in one move on '…'". Frame brief `Idea:` the mess object; `Not generic because:` it is
this business's own mess. raea: each receipt a named part; one `interpolate` progress drives all of them on staggered
offsets (3–4 f each) into one target transform, in-out-cubic, ≥ 12 f per part.

### Worked example
Topic: a home baker in Ipoh taking orders across WhatsApp, Instagram DMs and paper (illustrative).
- BEFORE: "Order bersepah" shown as three app icons and a sad emoji.
- AFTER: mess object = "a pile of order slips". Row 2: macro on a spike of 30 paper slips, two fallen. Fix row on "satu
  senarai": slips lift and stack into one clipboard list in one move; WhatsApp stays (she keeps it); accent on "30 order,
  0 tercicir".

### Check
- Can the mess be named as one object in ≤ 3 words?
- Is it cleared on screen in one continuous move, on a word?
- Does the clean state show what the viewer keeps?
- Does the move last ≥ 0.4 s, eased, without a wipe/flash?
