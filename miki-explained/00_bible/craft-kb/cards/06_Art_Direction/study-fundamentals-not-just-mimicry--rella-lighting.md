## METADATA
06_Art_Direction | craft-study process | principle for any look-test / reference-study loop

## CREATIVE_INTENT
The author copied a reference artist's visible steps (six steps: background, base colour, shadows, lights, details,
finishing effects) and still couldn't match the result or understand *why* a shadow or bounce light should go where
it does. The fix was not more copying, but studying lighting/colour fundamentals (a book on light and colour, named
light-source types, form vs cast shadow) — technique execution plus theory understanding, not technique alone.

## STE_PROCEDURE
1. If a look-test keeps missing the reference despite following its visible steps, stop and ask whether the gap is technical (steps) or conceptual (why).
2. If conceptual, study the underlying fundamental directly (light direction and colour theory, shadow types, composition/camera) rather than re-attempting the same copied steps.
3. Re-attempt the look-test using the fundamental understanding, not just the original step list.
4. Note separately when a result's shortfall is actually composition/camera/pose, not lighting — don't keep tuning lighting to fix a problem that is elsewhere (the author's own spotlight attempt was undermined by pose/camera, not light).

## AGENT_EXECUTION
When a Style D board/preview fails the fresh-critic rubric on a lighting criterion, check whether the real gap is a
missing fundamental (light direction, shadow type, composition) before iterating the same raea light values again;
if the critic's note is actually about pose/camera/composition, fix that layer instead of re-tuning lights.
### Worked example
Topic: a board-check pass where a hero prop's lighting "looks flat" despite following the gobo/rim checklist cards (illustrative).
BEFORE: keep nudging light intensity and gobo opacity, hoping one more pass will fix "flat."
AFTER: check first whether the big light/shadow shape (shape-hierarchy card) and form-vs-cast distinction are even
correct — if not, fix those fundamentals first, then re-apply the checklist.
### Check
- Before another iteration, was the gap diagnosed as technical (missed step) or conceptual (missing fundamental)?
- Is a lighting fix being applied to a problem that is actually composition, camera, or pose?
