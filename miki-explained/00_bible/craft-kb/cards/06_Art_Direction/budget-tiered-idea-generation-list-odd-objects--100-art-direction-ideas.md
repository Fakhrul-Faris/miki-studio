## CREATIVE_INTENT
When there's "no budget for a shoot", the exercise is to list every strange or unusual object the team/studio already
has access to (a fish in a bag, an odd prop lying around) and build the idea from what's already available, then
scale the same idea up if more budget exists (bigger props, more variations, a full campaign) — the list-first step
prevents chasing an idea that requires buying something new.

## STE_PROCEDURE
1. Before inventing a new prop for a setup, list what's already in the asset library (ASSET-SOURCES.md, kit dressing) that's unusual or visually strong.
2. Pick the idea that can be built entirely from that list at the lowest tier (one existing asset, no new commission).
3. If the episode's budget/time allows more, note a higher tier of the same idea (more variations, a bigger version, additional props) without changing the core concept.
4. Always execute the lowest tier that still lands the idea before reaching for a higher one.
5. Check: does the chosen tier require sourcing anything new, when a lower tier using existing assets would communicate the same idea?

## AGENT_EXECUTION
Frame-brief "Decision": name which existing library asset was chosen and, if relevant, which higher tier was
considered and skipped. Log any new asset only when no existing one would serve, per Studio-production-pipeline's
"fresh 2k assets per episode, log all in ASSET-SOURCES.md" rule.

### Worked example
Topic: a locksmith's "hidden fee for a duplicate key" (illustrative).
BEFORE: commissioning a custom-built oversized key prop to make the point visually big.
AFTER (lowest tier first): an existing CC0 keyring asset from the library, re-scaled and re-lit, already does the job —
no new asset needed; a "higher tier" (a fully custom giant key sculpture) is noted but skipped as unnecessary for this episode.

### Check
- Was the existing asset library checked before any new prop was considered?
- Was the lowest tier that still communicates the idea chosen first?
- If a higher tier was used instead, is there a reason the lower tier wouldn't work?
