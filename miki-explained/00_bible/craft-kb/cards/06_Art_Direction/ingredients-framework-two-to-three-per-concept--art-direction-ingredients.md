## METADATA
06_Art_Direction | Advertising/art-direction coaching (general) | frame-brief "Not generic because" field

## CREATIVE_INTENT
Art direction has an endless menu of visual ingredients (photography, type, colour, texture, DoF, casting, imagery
medium) but a dish needs "two to three standout flavors, not many." Like a chef, decide which 2–3 ingredients are
doing the real work for this concept — the rest should just support, not compete.

## STE_PROCEDURE
1. Before building a setup, list every visual decision it could use (light, colour, texture, prop choice, framing, type).
2. Circle only 2–3 that are deliberately tied to the insight — the rest default to the house style.
3. State each circled ingredient as a decision, not a vibe ("handwritten ballpoint pen, not Helvetica" — not "feels personal").
4. If a fourth ingredient is added, ask whether it's restraint-breaking decoration; cut it if it doesn't serve the idea.

## AGENT_EXECUTION
Frame brief "Not generic because" field lists exactly the 2–3 ingredients, each as a concrete choice (material,
colour, prop, angle) tied back to the Idea line, not an adjective.

### Worked example
Topic: a kedai runcit's expired-stock shrinkage (numbers illustrative).
BEFORE "Not generic because": "it feels urgent and relatable."
AFTER: "(1) the expiry-date sticker peeling off in macro — the one prop that is the whole idea; (2) brand accent only on
the loss number, nothing else lit warm; (3) the shelf gets visibly emptier each cut, no other change." Three ingredients,
each doing real work; everything else (camera, room, grade) stays the house default.

### Check
- Are exactly 2–3 ingredients named, each a concrete decision?
- Does each ingredient trace back to the Idea sentence, not a generic mood word?
- Would removing a fourth, uncircled decision change nothing about whether the idea reads?
