## CREATIVE_INTENT
For Ghost in the Shell's Hong Kong-inspired backgrounds, the art team shot both black-and-white and colour
reference photos of the same locations, assigned to two different artists, specifically to study tonal/contrast
behaviour (including environmental effects like humidity changing building contrast) separately from colour. This
separation of "does the tone/contrast read" from "does the colour read" produced the film's cinematic realism.

## STE_PROCEDURE
1. When gathering location/object reference for a background or environment, get or make a black-and-white version of the same reference, not just colour.
2. Study the B&W version for tonal structure and contrast specifically (what reads as near/far, light/shadow, foreground/background) before worrying about colour.
3. Note any environmental factor affecting contrast (haze, humidity, distance) as its own observation.
4. Build the colour pass on top of a tonal structure already confirmed to read correctly in B&W.

## AGENT_EXECUTION
In `ref_<shot>.md`, add a tonal note separate from the palette hexes: describe what reads as near/far and
light/shadow with colour removed (desaturate the reference image before describing it), then write the palette
section. Use this to catch a background that will "go flat" in Style D's dark room once colour is added.
### Worked example
Topic: a hazy street backdrop behind a hero object at a construction site (illustrative).
BEFORE: pick colours straight from a reference photo; the backdrop ends up with correct hues but a flat, same-depth read.
AFTER: desaturate the reference first, confirm which buildings read near vs far by tone alone, then reapply colour — the backdrop now holds depth even before the accent colour is added.
### Check
- Was the reference's tonal/contrast structure checked in black-and-white before colour was picked?
- Does the desaturated version of the planned frame still show a clear near/far, light/shadow read?
