## CREATIVE_INTENT
K-pop Demon Hunters used one fixed colour (crimson-violet) to "symbolize the demon throughout the film," foreshadowing
a character's inner struggle wherever it appeared, while a second colour (lavender/pink) marked the opposite,
"sweet, innocent and playful" state. The colour itself became a recognisable signal independent of the scene.

## STE_PROCEDURE
1. Pick one concept the episode (or series) needs viewers to recognise instantly, wherever it shows up.
2. Assign it a single colour that never changes meaning across setups.
3. Use a second, contrasting colour only for the concept's opposite state (safe/resolved vs. risky/hidden).
4. Never use that colour for anything else in the frame, so its appearance alone signals the concept.

## AGENT_EXECUTION
Since Style D permits only one saturated brand accent, this motif collapses onto the accent itself: reserve the
accent exclusively for the "thing to watch" (the hidden fee, the loss number, the catch) in every setup, and never let
it appear on anything else — so its appearance *is* the warning, the same way crimson-violet always meant "demon."

### Worked example
Topic: a phone instalment plan's hidden total interest (numbers illustrative).
BEFORE: accent colour used loosely — sometimes the brand logo, sometimes the price, sometimes a highlight.
AFTER: the accent colour appears on exactly one thing across all 11 setups — the real total once it's revealed (first
hidden, grey; then it pops in accent colour the moment the true RM4,200 appears) — so by setup 6, the viewer's eye
jumps to the accent colour the instant it appears, expecting the catch.

### Check
- Does the accent colour mean the exact same thing (the catch/hidden cost) every time it appears?
- Does it never appear on anything else in the frame (logo, neutral props)?
- Would a viewer who saw only the accent-coloured object in each setup still get the episode's point?
