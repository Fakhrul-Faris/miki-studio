## METADATA
06_Art_Direction | traditional drawing (tool-agnostic) | frame brief (Idea / Decision fields)

## CREATIVE_INTENT
A stiff pose is a pose without a purpose. Before posing anything, get "an interesting idea": the artist picks an
object the character interacts with, then asks how that character's personality would react to it. The concept gives
every later choice (line of action, weight, foreshortening) a reason.

## STE_PROCEDURE
1. Before choosing any pose, name the one object the subject interacts with in this setup.
2. Write in one sentence how this subject reacts to that object (wary, proud, tired, curious).
3. Choose the pose (or object state) that shows that reaction without a caption.
4. If no object or reaction can be named, rewrite the Idea field before picking a pose.

## AGENT_EXECUTION
Frame brief: fill **Idea** as "<subject> + <object> + <reaction>" before **Decision**. Style A/C: pick the MPFB library
pose that holds that reaction (static; no walk/gesture cycle). Style D: no people — the "reaction" becomes the hero
object's state toward a second object (a wallet pinned under a bill, a phone leaning away from a QR stand).
### Worked example
Topic: a kedai runcit in Shah Alam losing ~RM300 a month (illustrative) to expired stock.
- BEFORE (generic): "Figure standing beside shelf." — no object, no reaction.
- AFTER: Idea "owner + expired milk carton + quiet dread" → Decision: library figure holding a seated, shoulders-down
  pose on a stool, facing the chiller; the carton with the red date in the foreground (accent on the date).
  Style D variant (no people): Idea "milk carton + bin + about to fall" → carton tipped over the bin edge, date facing lens.
### Check
- Does the Idea field name one object and one reaction?
- Can the reaction be read with the sound off?
- Is the pose static (no implied walk or gesture)?
