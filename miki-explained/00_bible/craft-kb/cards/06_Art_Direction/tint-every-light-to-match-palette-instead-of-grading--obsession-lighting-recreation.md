## METADATA
06_Art_Direction | set.a.light 3D virtual gaffer (other) | raea light colour (adapted)

## CREATIVE_INTENT
Instead of grading the whole image afterward, set every light in the scene to the target palette's colour (e.g. all
lights to cyan, for a teal-orange reference) so the palette match happens at the light-authoring stage.

## STE_PROCEDURE
1. Before tinting, name the reference's two-colour palette (e.g. teal shadows / orange highlights).
2. Set the scene's cooler lights (fill, ambient, backlight) to the shadow colour.
3. Set the warmer/key light to the highlight colour.
4. Treat this as a substitute for a grading pass only when no grade step exists in the pipeline.

## AGENT_EXECUTION
⚠ Adapted: our house rule keeps ONE saturated brand accent only on what the line is about; tinting every light to a
two-colour palette would wash that out. Use this technique only on the scene's neutral/ambient lights (fill, rim,
backlight), tinted toward a single desaturated complementary colour (e.g. cool blue shadows). Never tint the key
light or the accent-coloured hero element — the accent stays the one saturated colour in frame.

### Worked example
BEFORE: a cold warehouse shot with all-neutral lights; reference calls for a teal-orange night mood.
AFTER: frame brief Decision: "ambient + rim lights tinted cool blue (desaturated, not the accent); key light stays
neutral; the RM price tag keeps the single orange brand accent — no other light carries that colour."

### Check
- Does only the ambient/fill/rim get the palette tint, never the single brand accent?
- Is the accent colour still used on exactly one element per the line, not diluted across the whole scene?

## NOTES
- ⚠ Rule conflict with the one-accent-colour house rule; adapted as above — tint ambient only, never the accent
  light or the key light.
