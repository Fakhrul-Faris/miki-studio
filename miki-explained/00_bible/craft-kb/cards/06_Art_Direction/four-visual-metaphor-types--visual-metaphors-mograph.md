## CREATIVE_INTENT
Metaphors link an abstract concept to a recognisable image. Four ways to build one: **Substitution** — replace a concept
with an image of similar meaning (climbing a mountain = effort). **Transformation** — an object changes shape into
something else (tears become a sea). **Combination** — two elements fuse into a new message (an eye made of clocks =
obsession with time; "the clock does not replace the eye; together they generate a new concept"). **Movement** — the
motion itself carries meaning (going down = despair; climbing faster and faster = hope of being close to success).

## STE_PROCEDURE
1. Before you brief, confirm the voice line is itself a metaphor; if not, show it literally.
2. Prefer Transformation: it is an object state change, the Style D native move.
3. Use Combination when two real objects from the topic can fuse into one hero.
4. Use Movement to encode direction (up = gain, down = loss) on the hero's own motion.
5. Use Substitution last; it adds a new object outside the topic.

## AGENT_EXECUTION
Frame brief "Idea" names the type. raea: Transformation = morph/scale swap of the hero over ~0.4–0.8 s, eased;
Movement = eased translation, speed caps apply.

### Worked example
Line (a metaphor in the script): "Duit korang bocor sikit-sikit tiap bulan."
- BEFORE: substitution — a cartoon leaking pipe appears.
- AFTER: transformation — the hero wallet's stitching opens and coins drip from the seam one by one, a counter beside it
  ticking RM5, RM10… (illustrative).

### Check
- Is the line itself a metaphor (else show it literally)?
- Is the type named, and does it use the topic's own objects?
- Is it one metaphor, not several?
