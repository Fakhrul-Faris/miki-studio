## CREATIVE_INTENT
A **setting** is the general time and place of the story; a **set** is a specific location inside it (Gotham = setting;
Axis Chemicals plant, the Bat Cave = sets). Set design starts with a **script breakdown**: the Edward Scissorhands
script names the photographs, the waterbed, the stuffed animals in Kim's room — the design then makes those listed
objects say who lives there. "This is how set design and world-building is done. One element at a time."

## STE_PROCEDURE
1. Before the shot list, write the episode's setting in one line (time, place, mood).
2. For each script line, list every concrete object it names or implies.
3. Group lines into sets (specific locations/surfaces inside the setting).
4. For each set, mark which listed object carries the line's meaning (the accent).
5. Design each object's details to say something about its owner or the mechanism.
6. Source every listed object before building; flag any line with no object.

## AGENT_EXECUTION
Add a breakdown table above the shot list: `| line | objects named/implied | set | hero object |`. Feed the "objects"
column into ASSET-SOURCES.md and the shot list's Setup column. A line with an empty objects cell is a "line shown only
in the voice" — fix the script or add the object before boarding.
### Worked example
Setting: "a 24-hour mamak in PJ after midnight, dark, one warm light." (illustrative)
- BEFORE (shot list): `| 3 | "Teh tarik untung paling tinggi" | close on cup | — |` — no object list, generic cup.
- AFTER: breakdown row `| L03 "Teh tarik untung paling tinggi" | glass mug, pull jug, condensed-milk tin, RM 2.50
  price strip | set 2: steel counter | mug (accent on the RM 2.50 → RM 0.60 cost split, illustrative) |` →
  shot-list row `| 3 | "untung paling tinggi" | macro on the steel counter, mug + tin + price strip | price strip
  splits into RM 0.60 cost / RM 1.90 profit on "untung" | setting-vs-set |`.
### Check
- Is the setting written in one line before any set is designed?
- Does every script line have at least one concrete object listed?
- Does each set name one hero object that carries the line?
