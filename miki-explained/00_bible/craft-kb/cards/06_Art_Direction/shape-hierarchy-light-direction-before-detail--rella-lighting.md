## METADATA

## CREATIVE_INTENT
When you isolate just the shadow shapes of a well-lit illustration, you see big shapes doing the work of showing
light direction, and only small shapes carrying detail (e.g. light passing through a hat's weave). Thinking in this
hierarchy — big shape first, small shape after — makes adding light feel more straightforward and makes the whole
composition read as more cohesive, rather than adding detail shadows before the overall light direction is settled.

## STE_PROCEDURE
1. Before adding any detail shading, block only the big shadow/light shapes that show the light's direction.
2. Check that the big shapes alone already communicate where the light is coming from.
3. Only after that reads clearly, add smaller shapes for local detail (texture, small gaps, secondary bounce).
4. Do not let a detail shape appear before the big-shape pass is settled.

## AGENT_EXECUTION
In a frame brief, order the **Eye** and **Feeling** fields so the lighting block is decided before any prop/detail
notes are written; in raea, set the key light and confirm the hero's big light/shadow split on a still render before
adding any secondary lights, gobos, or surface detail.
### Worked example
Topic: a hero stack of RM coins catching the one top light (illustrative).
BEFORE: build the coin texture/engraving detail first, then try to find a light that makes it all read.
AFTER: block the big light/shadow split across the stack first (which side is lit, which falls into shadow) and
confirm it reads on a still — only then add the small highlight catching each coin's edge.
### Check
- Does the big light/shadow shape alone (no detail) already show the light's direction clearly?
- Was any detail shading added only after that big-shape pass was confirmed?
