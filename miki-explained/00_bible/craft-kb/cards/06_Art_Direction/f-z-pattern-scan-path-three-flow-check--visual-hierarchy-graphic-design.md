## METADATA
06_Art_Direction | graphic design layout patterns | board-check verification method

## CREATIVE_INTENT
Most Western-read designs default to one of two eye-scan templates: the **F-pattern** (top-left start, across, then
down and across again, most content left-aligned) or the **Z-pattern** (top-left → top-right → diagonally down to
bottom-left → bottom-right). Either works even with a center-weighted focal point, as long as the layout guides the
eye along the path. Before finalizing any layout, the **three-flow check** asks three simple questions: where do the
eyes land first, second, and finally — a fast way to catch a layout with no clear path at all.

## STE_PROCEDURE
1. Choose F-pattern (top-left → across → down-left → across) or Z-pattern (top-left → top-right → diagonal to bottom-left → bottom-right) as the layout's scan path, or a centre-weighted variant that still resolves to a first/second/last landing.
2. Place the frame's attract/intrigue/deliver elements (see the Attract-Intrigue-Deliver card) along that path in order.
3. Before finalizing, run the three-flow check: name where the eye lands first, where it lands second, and where it finishes.
4. If any of the three answers is unclear or ambiguous, the layout needs reworking — this is the fast test for "does this have a visual pathway at all."

## AGENT_EXECUTION
In the board check, add a line per still: "scan path: [F/Z/centre] — 1st: ___, 2nd: ___, last: ___." Use this
alongside the existing board-check criteria (subject band, no clipping, one accent) as an extra pass/fail gate.
### Worked example
Topic: a how-to step still showing a phone screen, a hand gesture area (no hands per house rule — use a cursor/tap
indicator instead), and a step number (illustrative).
BEFORE: phone screen, step number, and a label are scattered with no scan logic — three-flow check comes back "unclear."
AFTER: laid out Z-pattern — 1st: the phone screen (top-left, biggest), 2nd: the step number (top-right), last: the
label/detail (bottom-right) — three-flow check now answers cleanly.
### Check
- Can the three-flow check be answered in one sentence each (1st/2nd/last), with no ambiguity?
- Does the first landing match the frame's intended attract element?
- Is the chosen pattern (F, Z, or centre-weighted) consistent with where other elements are placed, not fought against?
