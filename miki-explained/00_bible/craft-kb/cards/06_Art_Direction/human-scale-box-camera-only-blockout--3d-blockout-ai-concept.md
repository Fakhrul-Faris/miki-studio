## CREATIVE_INTENT
Before placing any other geometry, a simple box set to real human proportions (the source uses 183 cm height,
0.5 m width, 0.3 m depth) gives every other object in the scene an eyeball-able scale reference. Once placed, the
artist only worries about what's visible in the camera's frame — depth and detail behind or beside the lens's view
is deliberately skipped, since it won't be seen.

## STE_PROCEDURE
1. Before blocking out anything else, place one box scaled to real human height/width/depth as the first object in the scene.
2. Judge every other object's scale against that box by eye, not by precise measurement.
3. Frame the camera early and keep checking the scene through it as you block out.
4. Build and detail only what's visible in that camera's frame; skip depth/geometry behind, beside, or outside the frustum entirely (no floor under an object never seen from above, no back face never seen, etc.).
5. Remove the human-scale box once it has served its purpose (it's a reference, not a final asset).

## AGENT_EXECUTION
In the frame brief / blockout stage, add a throwaway human-scale reference (e.g. a 1.7 m cylinder) placed once per
new scene before any hero prop is scaled, and check every subsequent object against it and against the camera's
actual frustum before spending build time on unseen geometry.
### Worked example
Topic: blocking a macro hero prop (a drink can) against a kedai runcit shelf background (illustrative).
BEFORE: scale the shelf and can by guesswork, discover in the board check that the can reads too large/small for a human hand.
AFTER: a human-height reference box is placed once, the can and shelf are scaled against it by eye, and only the
shelf face visible to the macro camera is built — the back and sides of the shelf are left unmodelled.
### Check
- Was a human-scale reference placed before any other object was scaled?
- Is every detailed/modelled surface actually visible in the camera's frame?
- Was the human-scale reference removed/hidden before the frame is treated as final?
