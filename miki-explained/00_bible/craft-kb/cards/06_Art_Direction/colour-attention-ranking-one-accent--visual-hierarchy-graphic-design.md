## CREATIVE_INTENT
Colour is one of the strongest hierarchy tools: some colours (red, orange) sit at the top of an attention-grabbing
ranking and are what the eye goes to first — which is why alerts/notifications use them. A common, deliberately
simple tactic is a dull/greyscale design with exactly one element in colour: the eye has nowhere else to go.

## STE_PROCEDURE
1. Before colouring a frame, decide the single element that must be noticed first.
2. Keep every other element desaturated/neutral/greyscale.
3. Put the one saturated accent colour only on that single element.
4. If the accent sits in the red/orange family, treat it as an especially strong pull — use it only where the strongest pull is wanted (notifications, alerts, the hook object).

## AGENT_EXECUTION
In the frame brief, name the one element getting the accent before building; in raea, confirm with the existing
accent-coverage check (`colour-wheel-palette-schemes.md`'s AGENT_EXECUTION script) that only that element carries
saturated colour and everything else stays desaturated/neutral.
### Worked example
Topic: a dashboard screen showing one overdue bill among several paid ones (illustrative UI scene).
BEFORE: all bill rows use the same neutral colour with small text labels ("paid"/"overdue") — nothing pulls the eye.
AFTER: every row stays greyscale except the overdue row, which gets the one brand accent (in the red/orange family) —
the eye lands on it immediately, no label needed.
### Check
- Is there exactly one saturated-colour element in the frame?
- Is every other element desaturated or neutral?
- If the accent is red/orange, is it reserved for the single most important element (not spent elsewhere)?
