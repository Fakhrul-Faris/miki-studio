## CREATIVE_INTENT
A visual device works when there are "endless subjects you could slot in" but the pairing itself is what communicates:
LEGO brick + mismatched shadow = imagination; a knife + any vegetable sliced clean through the cutting board = this
knife is sharp; hashtag symbol + any face = this is where the conversation is happening. No copy is required because
the pairing *is* the argument.

## STE_PROCEDURE
1. Identify the one fact the payoff setup must prove.
2. Find a second element (shadow, counterpart, overlay, reaction) whose relationship to the hero object proves that
   fact visually, without naming it.
3. Make the pairing swappable — if changing the specific scenario still works, the device is doing the work (not a
   one-off coincidence).
4. Keep the frame to just the hero + the one paired element; no clutter.

## AGENT_EXECUTION
Frame brief "Decision" field: name the hero object and the one paired element, and state the fact their relationship
proves. Shot-list row: the state change is the pairing appearing/resolving (e.g. the shadow not matching, the cut
going clean through).

### Worked example
Topic: how a 0% instalment plan secretly adds the interest into the sticker price (numbers illustrative).
BEFORE: narrator says "the price already includes hidden interest" over a generic price tag.
AFTER device: the price tag shown next to its own shadow — but the shadow is a taller, second price tag (the real
"0% interest" cost folded in). No caption needed; the mismatch between object and shadow proves the hidden markup.

### Check
- Does the pairing prove the fact without reading the caption?
- Is the frame just the hero object + one paired element, nothing more?
- Could the same device work with a different hero object (proving it's a real device, not a one-off)?

## NOTES
- Visual gaps: none — LEGO shadow, knife/cutting-board and hashtag examples are each fully describable from narration.
