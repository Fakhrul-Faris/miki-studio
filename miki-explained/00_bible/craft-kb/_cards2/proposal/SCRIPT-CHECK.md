# SCRIPT-CHECK — run on every script draft before showing it (RECIPE-D §3)

Each line is a yes/no test taken from a craft-kb card (open the card for the method and a worked example).
Any "no" → fix before showing. Report the result as a ticked list under the script in `episode.md`.

**Before writing lines**
1. Are `Frame 0` and `Last frame` (same object, same framing) written first, and does the story fit mess → choice →
   result? — `masters/07_Script_Story/last-frame-first-then-fill-the-middle.md`
2. Is there a Beats v0 outline (6–8 beat phrases) whose joins are all "but" or "therefore"?
   — `cards/07_Script_Story/beat-wall-outline-before-lines--stone-parker-nyu.md`

**Hook (L01–L02)**
3. Zero greeting; spoken L01 ≤ 20 words; frame-0 text ≤ 8 words; exactly one anchor (number, object) on screen in
   frame 0? — `cards/07_Script_Story/cold-open-under-20-words-with-one-anchor--vox-explainer-script.md`
4. Can the hook only be understood by seeing it, and is it moving in frame 0?
   — `cards/07_Script_Story/effective-visual-hook-must-be-seen--fern-documentaries.md`
5. Context → interjection → contrast/snapback in the first two lines?
   — `cards/07_Script_Story/three-step-hook-context-lean-interjection-snapback--irresistible-hooks.md`

**Middle**
6. Is every join between lines literally "tapi / jadi / sebab tu" (but / therefore), never "lepas tu" (and then)? One
   main But for the episode? — `masters/07_Script_Story/and-but-therefore-not-and-then.md`
7. Is every analyst term replaced by a verb + RM number, and does each plain line still match the verified fact?
   — `cards/07_Script_Story/jargon-sentence-to-plain-sentence--explain-anything-clear.md`
8. If an analogy is used: is the line itself a metaphor, and is the analogy built part by part?
   — `masters/07_Script_Story/build-analogy-part-by-part.md`
9. Is there no voice line that only repeats what the picture shows?
   — `masters/07_Script_Story/filler-audio-filler-video-cut-to-terse.md`

**End**
10. Last line ≤ 7 words, a side-taking question (never a follow request), looping to frame 0?
    — `masters/07_Script_Story/last-frame-first-then-fill-the-middle.md`

House rules still apply on top (RECIPE-D §3, `script-formula.md`, claim ledger).
