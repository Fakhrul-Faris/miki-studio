## Extra step: staggered slide-up entrance across the separated layers
This file confirms the same screenshot-separation workflow (a real app/website screenshot cut into individually masked
sections, anchor points reset to centre via a plugin, pre-composed) and adds the entrance choreography the master card's
source doesn't detail: once every section is its own layer, all layers get the same slide-up-from-below + ease-ease
position keyframe, and then a "motion offset" tool is used to stagger each layer's start time a few frames apart (rather
than all sections arriving together) — so the rebuilt screen assembles top-to-bottom (or in whatever order reads best)
instead of popping in as one block.
