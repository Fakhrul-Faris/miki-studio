## Extra variant: CC Light Sweep, edge-only, one full rotation
A second recipe for the same "rim only lights up" look, applied to the glass shapes instead of a plain UI panel: CC
Light Sweep on a no-trackmat duplicate of the shape, with sweep intensity 0 (no face sweep), edge intensity 60, edge
thickness ~3, light reception "cutout" so only the silhouette's rim lights. Direction is keyed one full rotation (0 → 1,
i.e. 360°) over the shape's settle. Source note: "if the light sweep feels too fast, slow it down slightly for a
smoother glow."
