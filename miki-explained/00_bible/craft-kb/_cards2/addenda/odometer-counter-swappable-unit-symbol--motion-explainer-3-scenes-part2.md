## Extra variant: manual digit-sequence build (no counter script)
Where the master card's source uses a character-builder script to generate and key a digit comp, this video builds the
same "counting" read **by hand**: duplicate the text layer once per digit frame (e.g. a 10-frame block), type the next
digit value into each duplicate, arrange them in sequence so playback reads as the number ticking up (0→5→... →500),
then synchronise a second, true odometer/counter-script comp underneath so the two match and the manual version can be
trimmed once the timing feels right. Useful when no counter-expression script is available: build the illustion frame-
by-frame instead of via expression, then confirm the read against a real counter before finalizing.

VALUES BY SOURCE:
- Each duplicate held ~10 frames before advancing to the next digit.
- Counter target values used in this source: 0→500 (generic "money counter" stat), 0→22 ("8 seconds" stat context).
