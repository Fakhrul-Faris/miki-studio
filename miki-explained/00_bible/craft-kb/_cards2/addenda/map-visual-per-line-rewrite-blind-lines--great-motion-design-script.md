## VALUES BY SOURCE
| Source | Value / rule |
|---|---|
| Dan Neale (Motion Story) | The question for every line: "What is the animator going to show during this line?" If you can't immediately picture a clear, specific visual, the line isn't working. |
| Dan Neale | Density limit: if one sentence requires three different visuals, it is doing too much — split it; give each idea room to breathe. |
| Dan Neale | Three kinds of showable content: a scenario to illustrate, a transformation to show, a comparison to visualise. |

## Extra steps / variants
- Step 7 (new): count the visuals each line needs; if > 1 distinct visual idea (or > 2 setups' worth), split the line in two.
- Step 8 (new): tag each screen cell as scenario / transformation / comparison; a cell that fits none is blind.
- Example pair from source: blind "our platform delivers exceptional value" vs showable "watch three days of manual
  reporting collapse into a single click".
