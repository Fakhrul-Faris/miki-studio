## Extra steps / variants
1. Before a detail shot of an object with several parts, ask: must every part read? If yes, set f/7–8.
2. Compensate the darker image with light (key power / exposure), not with gain in the grade.
3. If only one part matters, keep house shallow DoF and focus on that part.
