## METADATA
06_Art_Direction | 3D staging / graphic design grouping (both tool-agnostic) | board check + set dressing

## CREATIVE_INTENT
Groups of similar objects read as more visually pleasing when the count is odd (3, 5, 7) rather than even — true even
when the layout is otherwise identical.
- Every Composition Concept states the base rule plainly: odd numbers of similar objects are preferred over even.
- Visual Hierarchy adds the compounding rule: placing one instance larger and centred, flanked by equal-sized
  instances on either side, automatically creates a focal point with no extra colour or light needed — and the two
  rules compound, so an odd-numbered group with one centred, larger hero reads cleanest of all. Rearranging the same
  objects unevenly (even at the same count) weakens the effect.

## STE_PROCEDURE
1. Before dressing, count similar objects in the frame.
2. If the count is free (not stated by the script), make it odd: 3, 5, 7 — never 4, 6 by default.
3. If the script states a number, show that exact number; never force a real count to a false odd number.
4. Within an odd group, make one instance (the middle one, or the hero) larger and place it at the centre.
5. Arrange the remaining instances in equal-sized sets mirrored on either side of the centred one — symmetry, not a random scatter.
6. Avoid uneven arrangements (some larger, oddly placed) even at the same odd count — the hierarchy weakens; check the still against a symmetric rearrangement.

## AGENT_EXECUTION
Board-check row: "similar-object groups odd unless a scripted count." Shot-list Setup column: write the count ("3
cups"). For any Style D "multiply with a counter" event (coins, products, customers), default the displayed count to
an odd number where it doesn't contradict the real figure, scale the centre instance up slightly, and mirror the
rest symmetrically either side in the frame brief's Eye field.

### Worked example
Topic: "Kedai kopi kecil: berapa cawan sehari baru untung?" (illustrative), and a "5 customers walked past, 1 bought"
counter visualisation outside a stall (illustrative, kept real to the claim).
- BEFORE: two cups and four sugar sachets dressing the hero kettle; five customer icons scattered unevenly with no clear focal point.
- AFTER: three cups (middle one sharp under the key light), five sachets in soft focus behind — the L05 line "120
  cawan sehari" is shown literally (counter ticks to 120), not forced odd. The five customer icons (odd count,
  matching the real number) are arranged with the one who bought centred and slightly larger, two smaller icons
  mirrored on each side — an automatic focal point with no extra colour needed.

### Check
- Is every free-count group odd, and does every scripted number appear exactly (never falsified to be odd)?
- Is exactly one instance in the group larger and centred, with the rest in equal-sized mirrored sets?
- Is the hero at the group's centre or otherwise clearly first, and would an uneven rearrangement of the same objects read worse (if so, keep the current symmetric layout)?
