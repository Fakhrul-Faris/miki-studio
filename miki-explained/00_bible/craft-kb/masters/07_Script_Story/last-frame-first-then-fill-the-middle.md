## METADATA
07_Script_Story | general (motion-graphics storytelling article) / Kallaway | Script v1 skeleton: `Last frame:` / `Frame 0:` written before any line, then the middle

## CREATIVE_INTENT
The best place to start a short script is the end, worked out before anything else is written.
- Motion Graphics Storytelling frames it as a visual exercise: "write the last frame first: what does the world look
  like once your product is in it? Then write the first frame: the same world without it." The middle is only "the
  moments that move the viewer from one frame to the other," and the story should fit 3 frames — mess, choice,
  result — cutting a 4th frame if the story needs it to make sense; narration should "say what the drawings can't,"
  cutting any line that only describes what's already on screen.
- How To Become A Master Storyteller frames the same end-first order as a line-writing exercise: write L01 and the
  last line before the middle, make the last line "the last dab" — so memorable it would be shared alone — and since
  short videos loop, the last line sets up the first line on replay, the way a baseball nine-hitter sets the table
  for the top of the order.

## STE_PROCEDURE
1. Write the last frame first: the hero object in its after-state, one sentence; write frame 0 next: the same object, same framing, in its before-state.
2. Write the story in 3 frames: mess, choice, result; if the story needs a 4th frame to make sense, cut the 3rd and rewrite.
3. Before writing any middle line, also write L01 and the last line as a pair, leaving the middle empty.
4. Make the last line ≤ 7 words on screen, a question the viewer can take a side on (⚠ adapted from "shareable statement" — RECIPE-D forbids a follow request).
5. Test the last line alone: would someone who heard only this line want to answer or share it? Check it leads back into L01 on replay (same object, same tension).
6. Fill the middle only with beats that move frame 0 to the last frame, using but/therefore beats; for each step/level, write its own before and after and cut any step with no after.
7. Strike every narration line that only describes what is already on screen.

## AGENT_EXECUTION
In `episode.md`, above Script v1, write two lines: `Last frame:` and `Frame 0:` (same object, same camera). These
feed the shot list's first and last rows (RECIPE-D loop). Then write the 3-frame line (`mess → choice → result`) and
map it: mess = L01–L02 (hook + open loop), choice = L03–L08 (mechanism / steps), result = L09–L11 (payoff + end
question). For an S16 how-to, each step row in the shot list must name its own before → after state change. Script
v1 skeleton: write L01, leave a gap of ~9 empty rows, then the last line; shot list: the last row's framing matches row 1.

### Worked example
Topic: a kedai runcit in Kajang whose shelf has expired stock (illustrative), and fake "harga asal" on sale tags.
- BEFORE: writer starts at L01 with "Ramai kedai rugi sebab stok" and discovers the end at L11; last line written
  last: "Jadi, hati-hati masa sale. Follow untuk tips lagi." (statement + follow request).
- AFTER: Last frame: the same shelf, front row all newest dates, one tin glowing accent. Frame 0: that shelf, close,
  a dented tin with last month's date. 3 frames: mess (tins mixed, 6 expired) → choice (oldest to the front, every
  Monday) → result (0 expired, RM36 not thrown away — 6 tins × RM6, illustrative). L11 on frame-0 framing: "Stok
  lama kat depan… atau kat belakang?" Sale-tags example, written end-first: L01 "Diskaun 50%. Tapi harga asal tu,
  pernah wujud ke?" Last line: "RM99 ni, murah betul ke korang kena?" — back on the same RM199→RM99 tag as frame 0;
  on replay, L01 answers "pernah wujud ke?" again.

### Check
- Are `Last frame` and `Frame 0` (same object, same framing) written before any script line?
- Does the story fit mess → choice → result without needing a 4th frame, and does every step have its own after-state?
- Were L01 and the last line written as a pair before the middle, with the last line ≤ 7 words, a question (not a statement or follow request), and looping into L01 and frame 0?
- Is there no voice line that only repeats what the picture shows?
