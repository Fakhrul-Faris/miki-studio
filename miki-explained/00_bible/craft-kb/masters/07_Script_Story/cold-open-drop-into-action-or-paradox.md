## CREATIVE_INTENT
Never open on scene-setting or a topic announcement ("Hari ni kita cerita pasal…", "Let me tell you…"). Instead drop
the viewer straight into either the single most surprising action in the story (in media res) or a stark paradox —
two things that shouldn't both be true, side by side — so the viewer feels "we're in something already, we're not
ramping up to it."
- Johnny Harris adds the action mode and its emotional handling: list the single most surprising action or visual
  first, start L01 with that action (agent + verb) or a "Tengok ni / Look at this" over it, write frame 0's
  emotional tone in ≤ 4 words beside the line (e.g. "tense, quiet, close"), and make frame 0 already moving on that
  action — no ramp-up shot, except when the topic genuinely needs context first, and then only ≤ 1 line of it.
- LEMMiNO adds the choice rule and the paradox mode: choose in media res when the topic has a visual, dated pivotal
  moment (a closing day, a price jump); choose paradox when the topic is a rule or system with no single moment —
  two true facts shown side by side on the hero object; either way, write frame-0 text ≤ 8 words, with context
  always coming after, never before.

## STE_PROCEDURE
1. Before writing L01, list the topic's single most surprising action/visual AND its stark paradox (two true facts that shouldn't both hold).
2. Choose in media res when the topic has a visual, dated pivotal moment; choose paradox when the topic is a rule/system with no single moment.
3. For in media res: start L01 with the action itself (agent + verb) or "Tengok ni / Look at this" over it.
4. For paradox: write frame-0 text ≤ 8 words stating both facts side by side; L01 follows with the specifics.
5. Delete any L01 that announces the topic instead of showing it.
6. Write frame 0's emotional tone in ≤ 4 words beside the line (e.g. "tense, close, quiet").
7. Make frame 0 already moving on the action or already showing both paradox facts — never a static ramp-up shot.
8. Use a ramp-up opening only when the topic truly needs context first, and keep it to ≤ 1 line even then.

## AGENT_EXECUTION
Script L01 + shot-list row 1 / frame-0 text: the "State change and events" cell holds the action (or both paradox
facts) already happening at frame 0; add a tone tag for the action mode.

### Worked example
Topic: a kedai bundle in Penang that buys stock by the bale (action mode), chained with why a kedai makan with a
long queue can still close down (paradox mode) — both illustrative.
- BEFORE (action): "Hari ni aku nak cerita pasal bisnes baju bundle."
- BEFORE (paradox): "Hari ni kita bincang kenapa kedai makan tutup."
- AFTER (action): L01 "Satu bal baju, RM800, dibelah — dan kedai tak tahu apa ada dalam tu." Frame 0: macro of a
  cutter slicing the bale strap, strap springing open; tone "tense, close, quiet".
- AFTER (paradox): frame-0 text "Beratur panjang. Tapi tutup kedai." L01 "Jual 300 pinggan sehari, tapi akaun dia
  merah." Frame 0: macro of a tray of order slips piling up while a shutter's shadow slides down over them.

### Check
- Does L01 contain an agent doing a visible action, or state a paradox as two true facts — with no topic announcement?
- Is frame-0 text ≤ 8 words, with context coming after, never before?
- Is frame 0 already moving on the action, or already showing both paradox facts (no ramp-up shot)?
- Is a tone tag (≤ 4 words) written for frame 0, and does any sound stay a subtle accent, never a stinger?
