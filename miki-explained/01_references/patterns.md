## Grammar so far (what each element means)

- **Accent red line** = the thing that matters / the problem.
- **Dot** = a person or data point. **Dot + ripple** = "look here".
- **Outline box** = facts about this subject.
- **Dashed lines + pink fill** = "measure this part".
- **Dark theme** = the struggle. **Light theme** = understanding.
- **Heavy caps** = claim. **Mono caps** = evidence.
- **Grayscale photo** = real humans (mixed media). **Colour** = data only.
